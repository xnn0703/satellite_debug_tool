# M19-A.4 可视化试产配置与批次生成开发记录

## 2026-09-18：实施启动

- 用户已确认 `M19_A4_production_configuration_plan.md` 和验收标准。
- 当前批次页依赖手工导入 schema v1 配方，配方中的 `fixtures.power_profile` 只是字符串，正式批次尚未解析电源档案或执行 PSW 控制。
- 当前启动门禁冻结所有匹配且就绪的在线设备，没有目标数量合同。
- 本轮按单一配置 owner 实施：设置管理版本化档案，批次页面只选择档案并生成不可变快照。

## 实施记录

- 新增 `ProductionConfigurationStore`，以单个原子目录文件管理产品模板、电源档案和工作站配置。每个对象使用稳定 ID、revision 和 SHA-256；导入包先完整解析、校验引用和摘要，再一次性替换目录文件。
- 设置页新增“试产配置…”入口。管理窗口用表单维护三类配置，电源型号下拉框当前只注册 `GW Instek PSW80-27`，并可按当前表单执行“连接并识别”。
- 批次页改为选择产品模板、设备数量和工作站配置。`AFD01C × 2` 会直接显示单台 `12 V / 8 A`、合计 `12 V / 16 A / 192 W`、电源身份约束、支路能力和配置摘要。
- 创建批次时同时写入 `recipe.json` 和 `production_configuration.json`，后者包含已解析的产品、电源、工作站内容及各自 SHA-256。创建后锁定选择，后续设置变化不会修改批次快照。
- 启动门禁按 `target_device_count` 精确比较已确认且可录制的设备；`AFD01C × 2` 在 1 台或 3 台时均拒绝启动，启动后冻结两台身份。
- 正式批次新增 `ProductionPowerWorker`。批次先获取唯一夹具租约，再按所选电源档案执行身份确认、准备关闭、设定电压/总限流、OUTPUT ON 和实测电压确认；中止或关闭页面先完成 OUTPUT OFF 实测确认，再释放批次状态。
- 电源 SCPI 记录和汇总分别保存为 `power_supply_records.jsonl` 与 `power_supply_summary.json`。
- schema v1 旧配方没有电压、电流和电源连接信息，无法安全自动补齐。旧入口已从日常界面移除，读取代码仅保留给历史批次和迁移测试。
- 摇摆台与 MS-6222 在工作站配置中记录档案 ID，并在批次摘要中显示为已配置/人工门禁。本轮没有把这些 ID 伪装为已完成真机验证。
