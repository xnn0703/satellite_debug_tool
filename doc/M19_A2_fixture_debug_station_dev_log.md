- MS-6222 首期只用 RS-422 `460800 8N1`，不接 PPS、不写配置、不参与平台闭环。
- 无 MS 时允许工程移动，证据最高为 `COMMAND_SENT`。
- 停止只停止后续轨迹点，当前 A6T 自然完成，不自动回中。
- 所有每轴硬上限必须由工作站档案明确给出，不采用隐含频率上限。
- 标定结论和操作者结论均为 `ENGINEERING_ONLY`，不会授予正式 `POSE_VERIFIED`。

## 2026-08-23：软件实现完成

### 档案与控制

- 新增 `fixture_profile.py`：档案 schema/revision、严格 IPv4 endpoint、强制 SHA-256、修订冲突检测、每轴硬上限和进程内独占租约。
- `motion_platform.py` 的早期单步限制与绝对移动拆分已由 M19-A9 替换；当前使用单条 A6T 绝对运动和三轴正弦幅频/速度/加速度门禁。
- 新增 `fixture_control.py` 后台调度器。正常停止会等待当前 A6T 完成时间结束且不回中；应用退出只停止后续下发，平台继续执行已经发送的当前命令。
- 绝对运动和轨迹请求保持 busy 到当前最后一条成功 A6T 的计划完成时刻，避免操作者提前下发下一条命令覆盖尚未完成的动作。
- 平台目标按计划完成单调时间写入会话；UDP 成功始终只作为 `COMMAND_SENT` 证据。

### MS-6222、标定与指标

- 新增独立 `460800 8N1` 被动串口 worker 和纯 Python 流解析器，协议字段、固定帧长和 CRC32 与固件 C 实现一致。
- 支持 INSPVAXB、GNSS v1/v2、RAWIMUSB，保留原始帧、主机单调/墙钟、GPS 时间、协议版本和质量字段；坏帧只进入原始证据和统计。
- INSPVAXB 按 100 Hz 预留超过 60 分钟的指标窗口，图形窗口单独限制为最近 5 分钟，避免显示缓存无界增长。
- 新增引导式八阶段坐标标定、唯一事件 ID、标定文件哈希与质量门禁；未确认、响应不足、耦合过大或噪声过大时不计算误差结论。
- 新增四元数姿态误差、缺口感知插值、静态稳定/超调/漂移及动态幅频/相位/时延/残差/耦合指标。无 PPS 的相位与时延固定标记为工程估计。

### 页面与留证

- Production Workspace 新增“批次测试 / 夹具调试”二级页面，两者共享独占租约；夹具页无需批次和 DUT。
- 页面提供档案编辑、安全预检、MS 串口、单轴绝对移动、回中、显式 Z=0 复位、三轴轨迹预览与执行、实时目标/实测/误差曲线、标定引导和事件区。
- 会话异步保存 manifest、档案快照、平台命令、MS 原始/解析数据、姿态对比、事件、summary 和文件哈希；异常退出保存为 `incomplete`。
- 关闭活动会话前必须确认。普通完成会继续采集到当前 A6T 完成时间结束，再停止记录并计算指标。
- 60 分钟级会话的姿态对齐、指标汇总和比较文件写入均在收尾线程执行，不阻塞 Qt 主线程；异常退出优先保存原始证据并标记指标未完成。
- 新增文案已同步中英文；1024x600 英文和 1280x800 中文离屏截图检查无重叠、横向滚动或不可达主控件。
