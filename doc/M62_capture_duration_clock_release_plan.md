# M62 采集覆盖时钟修复与 v1.9.3 发行计划

日期：2026-11-03。来源：v1.9.2 Windows user 发布门禁稳定复现 `support_full_coverage_ns == 0`；用户已授权完成本轮发版。

## 根因

- 完整采集覆盖区间使用 `time.time_ns()` 计算持续时间。
- Windows 墙钟分辨率允许相邻两次读取相等；FULL 确认后立即停止时，真实发生过的状态区间被记录成 0。
- 墙钟适合保存可对齐事件时间，不是持续时间的权威时钟。持续时间必须由高分辨率单调时钟拥有。

## 实施

1. 录制开始/停止墙钟继续使用 `time.time_ns()`，只表达外部时间线。
2. FULL 区间起止和覆盖时长统一使用 `time.monotonic_ns()`；内部字段和 SDB summary 键明确命名为 monotonic。
3. 增加确定性回归：墙钟固定不前进，单调时钟前进时覆盖时长仍为正且等于预期。
4. `v1.9.2` tag 和隔离候选保持不可变，不晋升；版本切到 v1.9.3 后重新执行全部门禁、提交、tag 和四包发布。

## 边界

- 本修复只改变覆盖持续时间的时钟来源，不改变设备 ACK、采集档位、录制文件生命周期或墙钟事件时间。
- v1.9.2 未进入正式 TUF/下载目录，不作为已发布版本声明。
