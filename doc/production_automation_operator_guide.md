# 自动化设备测试现场指南

本指南说明自动化测试页面的操作流程。测试结果、录制质量和现场设备验收分别记录。

## 1. 测试前准备

1. 将电脑、被测设备和电源接入工位网络；确认网段可达、设备地址互不冲突，并按现场安全规程确认急停、运动范围和供电支路。
2. 在 Production 配置中选择工作站档案，确认电源、摇摆台、MS-6222 的实际端点、标定和工位能力。正式测试开始前，软件会按所选工位连接并检查运行所需的夹具反馈与 MS-6222 新鲜有效参考帧；`CONFIGURED` 仅表示档案已绑定，`READY` 表示已取得运行证据。
3. 选择产品与供电版本。内置只读预置包括 AFD01B2、AFD01C、AFD01D 各自的 12 V / 9 A 配置，以及 B2 的 24 V / 8 A、C/D 的 24 V / 5 A 配置。内置预置通过“复制为定制”修改；工位支路额定能力仍会单独校验。已有定制模板保留自身参数，使用前核对。
4. 选择设备数量、测试方案并填写批次 ID、操作员。检查显式启用的项目、各项时长及跟踪判据；固件、参数核验和导航汇总均按所选方案启用。固件未设精确预期或参数规则为空时记录为跳过。
5. 确认界面显示的保存位置。默认跟随设置中的录制目录，保存到 `录制目录/自动化测试/YYYY-MM-DD`；显式配置的自定义保存根目录继续生效。批次开始后输出目录和配置快照冻结。

## 2. 开始与观察

1. 点击准备区的“开始测试”。该入口完成批次创建、配置冻结并启动自动准备和执行，不需要先单独创建批次或手动启动批次。正式工位配置下，设备可以保持断电，由流程按所选供电版本准备电源并执行身份准入；开始条件或准备失败时，按页面显示的原因处理。
2. 准备阶段按页面状态等待设备数量、身份、采集和夹具准入。参与设备冻结后，按实际启用工况顺序运行，只显示本批次启用的节点。车辆与导航项目按所选方案及其证据要求执行；缺少执行或性能判据时记录为 `INCOMPLETE`。
3. 运行页使用横向节点显示当前项目和阶段，大号倒计时显示该工况固定窗口剩余时间；设备曲线按冻结的参与设备呈现，夹具状态条和事件区显示对应状态与原因。搜星计入静置/摇摆中上电窗口；默认须连续 5 秒有效锁定且 SNR>0，搜星最长 300 秒。锁定后摇摆在运动前完成稳定确认，起摆即进入正式观察。正式观察默认允许单次中断≤2秒、每30分钟最多5次（按工况时长向上取整折算）、累计≤正式观察时长的0.5%；三项均满足才符合性能判据。恢复需连续正常3秒，确认时间不计入中断时长；恢复前再次异常合并为同一次事件。窗口结束仍待恢复确认时记录为 `INCOMPLETE`，已确认超限的 `FAIL` 保留。界面显示中断次数、最长/累计时长和恢复状态。
   缺失样本、无效字段和超过2秒的采样间隔形成独立数据质量问题，窗口继续计时。环境影响可以记录原因，自动判据仍使用实际遥测，不据此删除事件。上述门限为可调整试行值，新批次冻结实际使用值；旧批次与历史报告保留原判据。
4. 摇摆中上电工况由流程协调 DUT 与 MS-6222 的共享供电时序。断电阶段 MS 参考数据可能随 DUT 一同中断；电源关闭、平台继续摇摆的阶段依据平台反馈决定恢复供电。供电回读确认后，系统重新建立参考采集并等待本阶段新到达的有效帧，断电前的旧帧不作为恢复后的准入证据。操作员观察页面显示的恢复/等待状态，不以旧姿态数据代替新参考。
5. 运动或供电出现现场危险时，优先使用实体急停并按现场安全流程处置；软件中止用于受控停止和证据收尾，不代替实体安全措施。

## 3. 完成、审核与下一批次

- 正常自动步骤结束后，批次 owner 自动按顺序恢复采集、结束录制、确认断电、冻结执行结果并生成逐设备报告与证据归档。页面进入终态后查看结果和收尾状态；若页面提示归档重试或硬件状态待确认，按提示处理后再开始下一批。
- 执行结论与报告结论分开。报告依据实际 SDB、解析错误和可分析遥测帧形成数据质量；执行结果为 PASS 但采集证据不完整时，报告结论为 `INCOMPLETE`。`PASS`、`FAIL`、`INCOMPLETE`、`ABORTED` 均可生成 V01 和对应证据。数据质量 `COMPLETE` 仅表示已实现的数据检查通过，不证明设备性能、INS 精度、真实供电或物理验收通过。
- 自动 V01 生成后，使用“审核报告”录入审核人并生成 V02；自动结论保留，审核结论和改判原因单独记录。性能结论、执行完整性和数据质量分别展示；缺少SDB、分析帧或存在判定质量缺口时，审核PASS入口保持关闭。报告尚未审核时显示未审核，不把自动 PASS 当成审核完成。
- 终态且资源收尾完成后使用“下一批次”。它清理上一批运行状态并保留可复用设置，下一次“开始测试”分配新的批次 ID 和独立输出。
- 中止批次会执行受控停止、收尾和证据归档；夹具故障或证据缺口可使相关结果成为 `INCOMPLETE`。如果资源或录制仍在收尾，等待页面状态明确完成后再继续。

## 4. 结果位置与证据边界

- 默认批次数据目录：`<设置中的录制目录>/自动化测试/YYYY-MM-DD/<batch_id>/`；批次冻结后，以页面显示的实际路径为准。历史批次仍使用创建时冻结的目录。
- 默认报告位于批次目录的 `reports/`；夹具、设备 SDB、配置快照、质量分析和归档清单由批次证据结构关联。自定义路径及迁移后的旧路径以页面显示值为准。
- 交付审核时检查报告、`evidence.zip`、`manifest.json` 及其中列出的 SHA-256；缺失或质量问题按报告原因处理。
- M51 软件回归和报告渲染已完成；真实共享供电下的完整恢复/断电顺序、六项预置对应的现场供电能力、Windows 原生报告显示及批次规模性能仍有各自验收边界。现场结论应记录实物、接线、设备与夹具证据，不由软件测试结果推定。
