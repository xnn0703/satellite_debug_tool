# 自动化设备测试操作指南

## 1. 当前可用范围

当前 `Ctrl+Shift+P` 打开的试产工作区已经具备以下能力：

- 按产品模板、设备数量和工作站档案创建批次。
- 在指定网段发现 1～4 台设备，校验产品身份、SN、硬件 UID 与 MAC 冲突。
- 按设备建立独立 SDB 录制，并冻结本批次参与设备。
- 根据设备数量自动计算 PSW80-27 的总限流值，完成身份、设定值、输出和实测电压闭环。
- 独立验证摇摆台、MS-6222 和电源，保存工程证据。
- 保存批次结果、每台设备证据 ZIP、manifest 和符合条件的 V1/V2 Word 报告。

生产页按工位档案和实时预检事实控制启动。配置完整只表示参数已经绑定；摇摆台反馈和 MS-6222 有效帧均达到“就绪”后，批次才允许启动。

## 2. 测试前准备

### 2.1 网络

1. 将电脑、被测设备和电源接入设备交换机。
2. 给每台被测设备配置不同的临时 IPv4 地址，保证同一批次内没有 IP 冲突。
3. 给电脑网卡配置可访问设备网段的地址。
4. 当前灵境 A6 默认控制端点为 `192.168.15.201:7408`；电脑同一网卡默认使用 `192.168.15.101:8410` 接收反馈。现场地址以所选摇摆台档案为准。
5. 确认系统防火墙允许本软件的 UDP、TCP 和串口访问。

### 2.2 硬件

1. 确认实体急停可用，摇摆台运动范围内无人和无障碍物。
2. 将设备并联接入电源支路，核对支路额定电流和总功率。
3. 固定 MS-6222，确认安装方向、杆臂值和当前工作站标定一致。
4. 正式连接设备前，先在独立页面完成电源、摇摆台和 MS-6222 的一次健康检查。

### 2.3 软件配置

1. 启动软件，按 `Ctrl+Shift+P`，确认进入试产工作区。
2. 点击右上角设置，打开“管理生产配置”。
3. 在“产品模板”中选择或建立型号模板：产品型号、单台电压、单台限流、期望固件、观察时长和启用项目。
4. 在“电源档案”中选择 PSW80-27，填写 IP、端口 `2268`、身份和额定参数，点击“连接并识别”。
5. 在“摇摆台档案”中选择型号，核对本机反馈 IPv4/UDP 端口、控制器 IPv4/命令端口和已确认坐标标定。
6. 在“MS-6222 档案”中选择 COM 口，核对固定波特率 `460800`、安装身份、质量门限和同一坐标标定。
7. 在“工作站档案”中用下拉框绑定电源、摇摆台和 MS-6222，并填写支路数、支路电流和报告品牌信息。
8. 在设置中选择报告输出目录；未配置品牌字段时报告会显示“未配置”。
9. 使用“导出配置包”备份已经确认的生产配置；配置包同时携带摇摆台档案和标定。其他工作站导入后必须重新绑定实际 COM 口并执行实时预检。

## 3. 独立夹具检查

### 3.1 电源测试

1. 打开“电源测试”。
2. 点击“连接并识别”，核对制造商、型号和序列号。
3. 点击“读取状态”，确认保护正常。
4. 执行一次开启和关闭输出，确认界面以实测电压给出闭环结论。
5. 保持输出关闭后再返回批次页面。

### 3.2 MS-6222 测试

1. 打开“MS-6222 测试”，选择串口并连接。
2. 开始采集，确认 Roll、Pitch、Yaw、GNSS/INS 状态和数据更新连续。
3. 停止采集，确认 `ms6222_sessions/<session_id>/` 已生成证据。

### 3.3 摇摆台测试

1. 打开“摇摆台测试”，连接运动控制器和 MS-6222。
2. 确认当前档案与坐标标定 ID 正确。
3. 在平台中心、运动范围安全的条件下运行自动资格测试。
4. 核对 Roll/Pitch/Yaw 正方向、运动停止、位置残差和 MS 姿态响应。
5. 执行低幅低频组合连续摇摆，确认轨迹停止后平台位于保护范围内。
6. 保存并导出 `fixture_sessions/<session_id>/` 诊断 ZIP。

## 4. 创建并启动批次

1. 返回“批次测试”。
2. 填写唯一批次 ID 和操作员姓名。
3. 选择产品模板、设备数量和工作站档案。
4. 选择批次原始证据目录。
5. 点击“创建批次”。创建后配置、配方和版本会冻结到批次目录。
6. 给全部被测设备上电，等待左侧槽位显示完整型号、SN 和实时 SNR。
7. 确认在线设备数量与选择数量完全一致；存在额外在线设备、身份不完整、重复 SN/MAC 或型号不符时不要开始。
8. 等待每台设备显示证据录制就绪。
9. 点击“开始批次”。软件先准备电源并确认电压，再冻结参与设备。

## 5. 工况执行

软件不会按等待时间推断硬件动作成功。使用右侧测试项目、夹具状态和底部事件区观察实际回执：

1. 固件版本核验。
2. 参数系统核验。
3. 静置对星。
4. 锁定后摇摆跟踪。
5. 摇摆中上电跟踪。
6. 台架动态模拟或人工车辆工况。

每次动作前确认电源、摇摆台、MS-6222 和设备录制均处于就绪状态。共享夹具故障会使相关工况进入 `INCOMPLETE`；单台设备指标失败只影响该设备。

## 6. 完成、中止和报告

### 正常完成

1. 确认所有已启用项目都进入终态。
2. 点击“完成并生成报告”。
3. 软件停止录制、确认电源关闭、冻结批次结果并归档每台设备证据。
4. `PASS` 或 `FAIL` 设备生成 V1 DOCX；`INCOMPLETE` 或 `ABORTED` 只生成证据 ZIP 和 manifest。
5. 点击“审核报告”，填写审核人；改判时必须填写原因，生成 V2 并保留 V1。

### 异常中止

1. 优先点击“中止”，等待受控停止和电源关闭确认。
2. 运动风险出现时先使用实体急停，再记录现场原因。
3. 不要强制结束软件进程；这会使设备录制、夹具证据或电源状态无法完成收尾。

## 7. 结果位置

- 批次原始数据：`~/.satellite_debug_tool/production_batches/<batch_id>/`
- 夹具证据：`~/.satellite_debug_tool/fixture_sessions/<session_id>/`
- MS-6222 证据：`~/.satellite_debug_tool/ms6222_sessions/<session_id>/`
- 电源证据：`~/.satellite_debug_tool/power_supply_sessions/<session_id>/`
- 单设备报告：`<报告根目录>/<日期>/<型号>/<SN>/<批次ID>/`

交付前校验 `manifest.json` 中 Word、ZIP 和关键原始文件的 SHA-256，并解压抽查设备、供电、平台和 MS-6222 的时间范围。

## 8. 放行边界

正式出货前仍需完成以下验收：

- 将全部工况接入唯一 `ProductionRunCoordinator` 和真实硬件动作执行器。
- 用一台设备完成完整三工况自动流程和报告复核。
- 用两台设备验证共享动作、独立结论和证据切片。
- 验证任一 DUT、网络、电源、摇摆台或 MS-6222 断线后的安全收尾。
- 验证 Windows 打包版本在目标工位连续运行。
