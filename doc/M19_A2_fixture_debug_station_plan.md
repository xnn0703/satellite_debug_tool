# M19-A.2 摇摆台与 MS-6222 夹具调试台计划

## 目标

在 Production Workspace 增加独立的“夹具调试”页面，使操作者无需创建批次或连接 DUT，即可安全地验证灵境 A6/A6T 摇摆台控制、被动采集 MS-6222 姿态参考，并保存可追溯的工程会话。

本里程碑只形成工程证据。A6 没有回读，MS-6222 首期没有 PPS，人工结论固定标记 `ENGINEERING_ONLY`，不得写入正式 `POSE_VERIFIED` 或夹具资格状态。

## 实施范围

### 1. 工作站夹具档案

- 档案保存于 `~/.satellite_debug_tool/fixture_profiles/`，包含 schema、revision、平台 endpoint、回中/复位位姿、轴符号、calibration ID 和 SHA-256。
- Roll/Pitch/Yaw 分别声明角度、频率、速度和加速度运行包线。任一周期运动包线缺失时，档案可查看但禁止启动周期轨迹。
- UI 只能在档案上限内配置动作，不能临时放宽上限；工程会话保存完整档案快照与哈希。
- 启动运动前必须确认平台已回中、区域安全、急停可用、安装牢固。页面关闭或进程结束后不保留确认状态。
- 正式批次和夹具调试通过进程内独占租约互斥。

### 2. 摇摆台控制

- 单步控制按逻辑绝对 Roll/Pitch/Yaw 下发，未选择轴保持最近一次成功发送的逻辑目标。
- M19-A9 已替换原分段模型：一次绝对移动发送一条 A6T，完成时间直接使用业务请求的总完成时间。
- 周期轨迹支持三轴独立启用、幅值、频率、相位、渐入、稳定、渐出和采样周期；启动前提供轨迹预览。
- 启动门禁检查角度、峰值速度 `2πAf`、峰值加速度 `(2πf)^2A` 和离散采样步长。
- “停止序列”仅阻止后续指令，当前 A6T 自然完成；回中和复位独立，复位到 `Z=0` 必须二次确认。
- MS-6222 不参与闭环伺服；缺失时仍可工程移动，证据最高为 `COMMAND_SENT`。

### 3. MS-6222 采集与标定

- 新增独立串口 worker，默认 `460800 8N1`，只被动读取 USB-RS422 数据。
- Python 流解析器与固件 `ms6222_protocol` 对齐，支持 INSPVAXB、GNSS、RAWIMUSB、v1/v2 探测、NovAtel 风格 CRC32、噪声恢复、分片和粘包。
- 每帧保存原始字节、主机单调时间、墙钟时间、GPS 时间、协议版本、CRC 与质量字段；无效帧只进入原始证据和统计，不更新 latest。
- 引导标定顺序为：回中静置、Roll/Pitch/Yaw 各 `+3°/-3°`、再次回中、自动识别轴映射/符号/零偏、人工确认。
- 标定文件保存于 `~/.satellite_debug_tool/fixture_calibrations/`，包含坐标变换、零偏、响应、交叉耦合、静态噪声、覆盖率和 calibration ID。
- 坐标或时间质量不满足门禁时只展示原始姿态，不产生正式精度结论。

### 4. 页面、记录与指标

- Production Workspace 使用“批次测试 / 夹具调试”二级切换；夹具页包含档案与连接、安全确认、单步控制、周期轨迹、实时目标/实测/误差曲线、事件和会话结论。
- 状态文案严格区分“档案有效”“预检完成”“指令已发送”，不得把 UDP 可发送描述为平台在线或已到位。
- 控制调度、串口采集、文件写入分别在后台执行，通过 Qt 信号更新 UI。
- 会话保存于 `~/.satellite_debug_tool/fixture_sessions/<session_id>/`，包含 manifest、档案快照、commands JSONL、MS 原始记录、解析 CSV、对比 CSV、events JSONL 和 summary JSON。
- 指标覆盖指令覆盖率/抖动、MS 报文率/CRC/有效率、静态误差/稳定时间/超调/漂移、动态幅值比/频率误差/估计相位、RMS/P95/最大残差和非目标轴耦合。
- 姿态比较先应用标定变换，再用四元数计算误差；Yaw 连续展开，数据缺口不跨越插值。
- 操作者可选择通过/不通过/无法判定并填写备注；会话结论始终为 `ENGINEERING_ONLY`。
- 所有新增 UI 文案同步中英文资源。

## 实施顺序

1. 建立夹具档案、校验、哈希和租约模型。
2. 扩展运动平台门禁、单步拆分和调度回调。
3. 实现 MS-6222 帧模型、流解析器与串口 worker。
4. 实现坐标标定、姿态对比、工程指标和会话记录器。
5. 新增夹具调试页面，接入 Production Workspace、主题和国际化。
6. 补齐单元/UI 测试、翻译资源和全量回归，最后按验收文档复核。
