# M41 时间范围下拉框文字布局验收标准

配套：[计划](M41_combobox_text_layout_plan.md)、[开发记录](M41_combobox_text_layout_dev_log.md)。

1. zh_CN/en_US × dark/dark_hc/light 下，全部预设选项完整可见，行文字位置一致。
2. 下拉框与弹出列表使用一致 UI 字体角色；数值框保留等宽字体。
3. 中英文动态切换后按内容重新计算宽度；选择和时间范围保持原值。
4. 回放与日志共用组件均采用修复后的布局；原有预设、自定义、程序化设置和信号回归通过。
5. 旧实现的内容裁切由回归测试稳定检出；新实现通过同一检查。
6. macOS 原生 Qt 保存三主题/双语言弹出列表视觉证据，Windows 原生视觉检查在对应平台复核。
