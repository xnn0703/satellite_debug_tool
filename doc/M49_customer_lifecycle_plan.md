# M49 客户工具连接、录制与退出生命周期计划

状态：2026-10-31 用户已确认范围并授权实施。对应用户本轮五项反馈，不提交、不打包、不操作现场设备。

## 目标和范围

1. 客户页面打开、设备自动恢复或工作区切换不自行连接外接电源。保存的电源档案只表示配置，用户显式“保存并连接”建立客户电源会话；离开客户工作区时保持既有释放所有权边界，返回时保持停止，自动化测试按自身批次启动链路独立连接。显式启动网络/功耗测试时，依照现有准入明确需要的电源连接，不能让页面可见性替代连接意图。
2. 修复设备断开/重连/遥测过期时的总览布局：长状态文字不扩大页面最小宽度，不推走端点输入、连接按钮和电源卡片；数值与过期状态保持清晰。固定 endpoint 的控件和 Store 保持归属，布局只呈现状态。
3. 自动化工作区的可见名称统一为“自动化测试 / Automated testing”，覆盖标题及同义工作区入口/提示。批次 ID、产品工位、历史文件、配方 schema、内部 production 标识保留业务兼容合同。
4. 复现录制中打开/关闭摇摆台、Shell 弹窗造成的实际中断；以 endpoint Runtime、录制 lease、SDB 帧时间和录制关闭事件确认根因。普通弹窗观察/焦点切换不得结束或重绑录制；真正物理掉电、设备重启、手动停止及独占写入事务分别按原合同报告，不能用界面状态掩盖实际缺口。若发现应用代码主动停止，修复权威生命周期或租约源。
5. Shell 连接或持续接收时，关闭弹窗和关闭主程序使用同一受控关闭事务。用户确认一次后启动断开、worker 收尾、RxRing 分帧终排空、decoder 与日志收尾，再自动完成原关闭意图；等待期间保持界面响应。取消确认保留会话，YMODEM 取消与独占租约释放沿用原合同。关闭失败明确说明原因并保留可恢复状态，避免重复确认与同步阻塞。

## 已核对证据与待确认根因

- `ui/customer_session_bundle.py::_sync_power_activity` 将 `_customer_active or iperf_active` 直接交给 monitor；`ExternalPowerMonitor._sync_worker` 在激活且已有 host 时创建连接。确认页面活动当前会触发客户电源连接。
- `ui/customer_overview_view.py::_MetricValue` 在同一 word-wrap 数值标签追加 stale 文案；需结合总览各布局 minimumSizeHint、宽度和密度策略稳定复现截图中的横向伸展，不能只截短一个字符串交付。
- `ProductionWorkspace` 的标题源键是 `Production batch test`，中文译为“小批试产测试”；需整体清点可见同义命名，维护 TS/QM。
- 打开摇摆台和 Shell 的入口只构建/显示弹窗；目前未取得其直接终止录制的证据。需检查构造副作用、会话租约、延迟事件、隐藏生命周期以及设备实际断连，建立稳定回归。
- `CustomerWorkspace.shutdown` 先确认、调用 Shell workspace.shutdown，随后再次 close dialog；dialog.closeEvent 又确认连接状态。controller.shutdown 提交断开并同步等待 worker，workspace 使用 processEvents 泵送终排空，Qt 关闭事件可在此期间交错。实施记录包含最终关闭事实边界和回归证据。
