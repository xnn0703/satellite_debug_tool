# 卫通终端管理工具 v1.9.1

英文名称：Satellite Terminal Manager。提供 Windows x86_64、macOS Apple Silicon 的客户版和运维版完整包。

## 自动化测试判据

- 初始搜星计入配方总时长；默认连续锁定且 SNR 为有限正值达到 5 秒后确认搜星完成，搜星最长 300 秒。
- 正式观察允许测试环境造成的短时波动：单次中断不超过 2 秒、每 30 分钟不超过 5 次、累计中断不超过正式观察时长的 0.5%，连续健康 3 秒后确认恢复。
- 失锁、SNR 非正值、非有限值和数据缺口分别记录；普通设备性能失败继续后续测试，共享夹具故障或主动中止进入统一收尾。
- 摇摆观察从平台实际开始运动且反馈有效后计时，判定器、阶段进度和页面倒计时使用同一观察窗口。
- MS-6222 当前用于提供有效、新鲜的姿态参考，不以安装角度误差作为本版设备性能失败条件。

## 配置、报告与供电

- 内置型号预置更新：AFD01B2 24 V 版本允许电流为 8 A；AFD01C、AFD01D 24 V 版本保持 5 A；12 V 版本保持 9 A。
- 执行节点严格遵循配方启用状态，未启用项目不进入测试流程；尚无正式判据的导航汇总明确记录为未完成。
- 报告分别保存设备性能、执行完整性和采集质量；缺少可分析证据时不把执行完成等同于报告通过。
- MS-6222 与被测设备共享电源时，自动化流程区分预期断电、重新上电、设备新代际、完整采集恢复和新参考帧，避免把准备阶段计入正式观察。

## 更新与分发

- Windows 由 GitHub Actions 构建，macOS 使用本地 Python 3.11 构建；四份候选均绑定同一发布提交并上传阿里云。
- 客户版使用完整包人工交付，不启用应用在线更新；设备固件升级功能保持不变。
- 运维版通过 HTTPS 和签名元数据检查更新；本次 Windows 候选提供完整包，文件级差量能力已实现，但本版未随候选发布差量包。
- macOS 运维版下载并校验完整 ZIP，退出应用后手动替换。

## 安装说明与边界

- 客户版应用名称为“卫通终端管理工具 / Satellite Terminal Manager”，不附加 User 或版本后缀；运维全量版保留 Ops 标识。
- Windows 运行 `SatelliteTerminalManager.exe`；macOS 将对应 `.app` 放入“应用程序”。不要把新版本文件混合覆盖到旧目录。
- 本次 macOS 包为 Apple Silicon 构建，最低声明 macOS 14；Windows 包为 x86_64 构建。
- 自动化测试判据为当前工程试行值；软件测试、冻结启动和下载校验不代替真实设备、供电、摇摆台、RF 与 Windows 实机升级恢复验收。
