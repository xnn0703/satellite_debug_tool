# M50 验收标准

状态：2026-10-31 用户已确认，与M50计划对应。

1. 断电状态可以创建批次；每台参与设备上电识别后自动申请完整采集，正式观察具有本代际响应及实际数据证据。
2. 在没有手动客户录制/工程Debug介入的独立自动化测试中，模拟设备仅在support_full成功后发送分析帧；SDB保存所有注入DataReport、INS及协议声明的其他帧，并可正常回放。
3. 固件未声明能力、响应失败、缺失数据、旧代际响应均产生准确原因，不准入完整采集状态；不静默退回只录摘要。
4. 动态上电和重启后重新建立采集证据；多设备采集、Runtime、租约及文件保持隔离。
5. 正常完成、中止、异常、退出均正确收尾；采集前Debug状态依协议恢复，原始数据和结果事件保留。
6. 采集质量报告区分请求已发送、设备已确认、实际数据已到达和文件已完成；逐设备展示实际帧类别及丢块/缺口。
7. 每项根因具有回归；相关与全量测试和翻译检查通过，文档记录与计划逐项比对。软件测试不替代真实设备验收。
