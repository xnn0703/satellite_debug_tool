# M26 客户页外接电源只读监测验收标准

状态：软件验收完成；真实 PSW/负载验收待执行

对应计划：`doc/M26_customer_external_power_monitor_plan.md`

## A. 所有权与只读安全

- [x] 全进程只有一个外接电源监测 worker、一个 TCP transport owner 和一个权威 Store；不同客户 endpoint 不重复连接。
- [x] IP 留空时不启动 worker、不发起 TCP 连接，客户页明确显示“未配置”。
- [x] 身份必须匹配 `GW-INSTEK / PSW 80-27` 后才显示在线并接收样本；身份不符时关闭连接并显示明确错误。
- [x] 客户监测发送的 SCPI 全部为查询命令；没有设定值、OUTPUT ON/OFF、任意命令或其他写入口。
- [x] 进入 Production Workspace 前客户监测 transport 已关闭；返回客户页后才按当前配置恢复。
- [x] 断线、超时、解析失败和应用退出均撤销在线事实并关闭 transport，关闭应用会等待 worker 正常结束。

## B. 当前状态与历史

- [x] 每个有效样本由一次权威采样产生，包含连接代次、时间、电压、电流、`V × A` 功率和只读电源状态。
- [x] 非有限、缺字段或失败响应不会显示/记录为真实零值，也不会继续把上一次读数标作实时。
- [x] 历史有最近 30 分钟/固定容量边界；重连保留同一配置会话历史但以连接代次区分，清空 IP 或重建 owner 时清空。
- [x] 明确重连只重新执行身份和查询，不产生控制命令。

## C. Customer Overview 与窗口

- [x] 底部四项按“变频板 / 发射阵列 / 接收阵列 / 外接电源”等宽排列，原三项即时状态与温度弹窗行为不变。
- [x] 外接电源摘要分别呈现未配置、连接中、在线、离线/读取失败等明确状态；在线时显示 V/A/W。
- [x] 点击外接电源打开独立窗口，显示当前身份/状态/V/A/W 和最近 30 分钟电压、电流双曲线。
- [x] 同一窗口重复点击只激活，不重复创建；切换客户 endpoint 后仍复用相同窗口和历史。
- [x] 窗口初始靠近点击锚点，支持原生最大化、最小化、关闭，并适配三种主题和中英文切换。

## D. 设置分区

- [x] Customer 设置显示外接电源 IPv4，固定端口 `2268` 只读，并说明“只读取，不控制输出”。
- [x] Customer 与 Engineering 设置不显示“管理试产配置”和试产报告字段。
- [x] Production 设置仍显示并可保存原有试产配置与试产报告字段。
- [x] 无效 IPv4 不能保存；清空 IP 可保存并立即停止监测。
- [x] scope 中隐藏的字段不被重置、覆盖或迁移到错误 owner。

## E. 客户录制

- [x] 客户 SDB v3 录制活动时，每个有效样本写入一个 `external_power_sample/v1` metadata 事件。
- [x] 事件时间、电源身份、连接代次、V/A/W、输出和保护/告警状态与 Store 样本一致。
- [x] 多 endpoint 同时录制时，每个活动 SDB 都收到样本；未录制 endpoint 不写入。
- [x] 录制队列满或写入失败不会阻塞 UI/监测线程，并进入现有 dropped 统计。
- [x] 工程 SDB v2、无录制状态和无效样本不写外接电源事件。

## G. 真机与外部边界

- [ ] 使用真实 PSW 80-27 核对 `*IDN?`、面板电压/电流、软件 V/A/W 和曲线时间线一致。
- [ ] 空载、稳定负载和功耗变化过程连续采样，无 UI 卡顿或并发 SCPI 响应错配。
- [ ] 客户监测运行期间确认电源设定值与输出状态没有被软件改变。
- [ ] 切入 Production 电源调试/批次控制时无双连接和命令交错，返回客户页后只读监测可恢复。
