# M19-A.7 摇摆台型号模板与自动档案计划

## 目标

- 操作者选择摇摆台型号后，由软件生成完整夹具档案，不再手工抄写通讯、运动包线和 A6 几何参数。
- 型号固有参数、安装实例参数和 MS-6222 坐标标定保持独立事实来源。
- 当前内置型号的 A6/A6T 服务端点为 `192.168.15.101:9800`；原始 `plat.xml` 中的 `192.168.15.201` 是 `ECMEthcat DriverEx`，两者保持独立语义。
- 设备几何和运动参数以用户提供的原始 `plat.xml` 为准；厂家服务程序目录内的另一份 XML 只用于确认软件架构，不覆盖当前型号参数。

## 数据模型

- 新增不可变 `FixtureModelPreset`，保存型号 ID、显示名称、协议端点、各轴运行包线、A6 工作位/复位位和最短指令时间。
- `WorkstationFixtureProfile` 增加 `model_id`，档案继续冻结模板展开后的全部控制参数和 SHA-256，保证历史会话可复算。
- 夹具档案 schema 升级到 v2；v1 档案校验原哈希后迁移为 `custom` 型号，不绕过原有完整性检查。
- 首个型号 ID 为 `lingjing-a6-200mm`，显示为“南京灵境六自由度平台（200 mm）”。

## 当前型号模板

- A6/A6T 平台服务 endpoint：`192.168.15.101:9800`；底层驱动地址：`192.168.15.201`。
- Roll/Pitch/Yaw 角度边界：`±30°`。A6T 单步限制经 M19-A9 复核无供应商依据，已从当前模型移除。
- 已批准工程运行包线：Roll/Pitch `0.3 Hz / 30 deg/s / 50 deg/s²`，Yaw `0.2 Hz / 20 deg/s / 20 deg/s²`。
- A6 工作位 `Z=100 mm`，复位位 `Z=0 mm`，当前控制 Z 范围 `0..100 mm`。
- 最短 A6T 完成时间 `20 ms`，对应资料给出的 50 指令/秒能力；M19-A9 默认轨迹采用 `50 ms`，`20 ms` 仅在真机资格验证通过后使用。
- 上述频率、速度和加速度是软件工程运行包线，不声明为厂家机械极限；真机验收前维持工程可试用状态。

## 界面

- 摇摆台测试页直接显示“摇摆台型号”下拉框，不再暴露“新建档案”和“重新加载档案”操作。
- 首次出现内置型号时，软件自动生成该型号唯一的内部档案；选择型号时直接加载对应档案。
- 软件发现已生成的当前型号档案仍指向 `.201:9800` 时，按 revision 规则升级为 `.101:9800`，保留轴符号和 calibration ID；由于档案 SHA 改变，既有标定必须重新匹配或重做。
- 型号拥有的 endpoint、角度、频率、速度、加速度、最短时间和 Z 几何只读显示。
- “安装配置”只保留三轴符号可选；内部档案 ID 和初始 calibration ID 由软件生成，引导标定通过后继续由既有流程替换为真实 MS6222 calibration ID。
- 编辑既有档案时显示其 `model_id`；v1 迁移档案以 custom 方式保留原参数，不自动覆盖。

## 验证

- 单元测试覆盖型号模板生成、字段值、v2 哈希以及 v1 档案迁移。
- UI 测试覆盖直接型号选择、自动档案、只读边界、安装方向配置及保存结果。
- 运行夹具档案、运动平台、夹具页面专项测试，更新翻译并执行全量回归。
- 真机验证仍包括 UDP 目标确认、三轴方向、引导标定、单步及组合轨迹；软件测试不替代物理运动验收。
