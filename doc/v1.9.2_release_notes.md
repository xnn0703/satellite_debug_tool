# 卫通终端管理工具 v1.9.2

发布日期：2026-11-03

## 主要更新

- macOS 运维版接入完整事务自动更新：退出前验证、App 外持久更新器、同盘原子切换、健康回执、登录恢复和失败回滚。v1.9.2 是该能力的桥接版本；从 v1.9.1 升级本版仍需人工替换一次。
- 发布复核改为 ECS 本机完整 SHA-256 加外部有界 HTTPS Range，避免发布校验占满服务器公网带宽。
- 预录制在设备上线前即可立即创建 SDB；完整采集协商失败转为可诊断的被动采集阶段，不再中断录制。
- 摇摆轨迹在发送前完成逆运动学和控制帧编译；连续轨迹使用固定周期程序，降低运行期负载和内存增长。
- 摇摆台增加“缓停并回正”流程，按渐出、回正、确认/失败阶段保存事实，不把命令发送等同于回正成功。
- 运动控制时间线迁移到独立进程；迟到保存时序故障并从真实发送时刻重建周期，不再因单次迟到无限保持当前位置。
- 完善 INS trace、录制阶段、夹具姿态和生产配置的相邻协议/证据处理及回归测试。

## 发行边界

- 用户版仍采用人工完整包交付，不启用应用在线更新。
- macOS 为 arm64 ad-hoc 签名，尚未 Apple notarization；Windows 系统签名和真实系统升级另行验收。
- 软件测试和归档验证不替代设备、RF、供电、MS-6222 或摇摆台现场验收。
