# M19-A.5 摇摆台与 MS-6222 独立调试验收标准

## A. 页面与所有权

- [x] Production Workspace 显示“批次测试 / 摇摆台测试 / MS-6222 测试 / 电源测试”四个入口。
- [x] MS-6222 页面无需批次、DUT、摇摆台档案或安全确认即可使用。
- [x] 独立 MS 页面没有运动控制入口；摇摆台页面仅在 M19-A9 联合资格测试中显式获取 MS 串口租约。
- [x] 同一 MS-6222 串口只有一个权威 owner；独立测试与正式批次明确互斥。
- [x] 摇摆台独占租约继续阻止批次与工程控制同时发送运动命令。

## B. MS-6222 连接与数据

- [x] 支持串口刷新、连接、断开和错误恢复，参数固定显示为 `460800 8N1`。
- [x] 串口打开与合法数据确认分开显示；未收到合法 CRC 帧时不能显示设备有效。
- [x] INSPVAXB、GNSS v1/v2、RAWIMUSB 均可自动识别并显示最新值。
- [x] 显示各帧计数/频率、CRC 错误、无效长度、噪声丢弃、最近数据时间和协议版本。
- [x] 显示姿态、质量状态、GNSS 和原始 IMU；姿态曲线限频不丢弃原始证据。

## C. 独立会话与证据

- [x] 独立采集保存到 `ms6222_sessions/<session_id>/`，不写入摇摆台 `fixture_sessions`。
- [x] 会话包含配置、原始帧、解析数据、统计、事件、summary、manifest 和文件 SHA-256。
- [x] 正常结束支持通过/不通过/无法判定和备注，结论固定为 `ENGINEERING_ONLY`。
- [x] 串口断线、连续无有效数据、写盘失败和异常退出保留已有证据并标记 `incomplete`。
- [x] 连接可以独立保持，只有开始采集后才写正式会话证据。

## D. 摇摆台单独验证

- [x] 摇摆台档案、安全确认、单步、回中、Z=0 复位和组合轨迹功能保持可用。
- [x] 无 MS-6222 时可完成工程运动测试，证据最高为 `COMMAND_SENT`。
- [x] 摇摆台会话不生成实测姿态、姿态误差或 `POSE_VERIFIED`。
- [x] 网络失败、中止、关闭页面和长轨迹调度保持现有安全语义。

## E. 兼容与联合边界

- [x] 历史 `fixture_sessions` 继续可读取，文件和摘要不被迁移或改写。
- [x] 现有 parser、CRC、serial worker 只有一个实现，不复制第二套协议逻辑。
- [x] 联合资格测试明确获取摇摆台与 MS-6222 两项所有权，独立 MS 测试占用串口时拒绝启动。
- [ ] 正式批次可同时引用平台和参考档案，并把两条证据关联到同一单调时间线。

## F. 自动化与真机验证

- [x] 单元测试覆盖串口独占、合法帧确认、坏帧/噪声恢复、断线、写盘失败和 manifest 完整性。
- [ ] UI 测试覆盖无批次连接、开始/停止采集、页面切换、关闭确认和中英文运行时切换。
- [ ] 1024×600、1280×800 和 Windows 125%/150% DPI 下四个入口及主要控件可达。
- [x] 翻译 `update`、`check` 和全量 pytest 通过且无新增 warning。
- [ ] 真机完成 MS-6222 单独连接、三类报文、断线恢复和至少 60 分钟独立采集。
- [ ] 真机完成无 MS 的摇摆台单步、回中、三轴组合轨迹和中止测试。

> 两个单设备调试页通过只证明各自通信、控制或采集链可用。绝对姿态精度与整机动态响应仍需联合标定和正式批次证据。
