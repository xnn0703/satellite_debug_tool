## A. 数据历史

- [x] 三部件温度历史由 `ProductServiceStore` 统一维护，不建立第二条协议/状态链。
- [x] 仅接受 `0x23` 中 temperature valid 且有限的温度；无效字段不会被记录为 `0 °C`。
- [x] 历史使用设备 uptime，能正确处理乱序与 u32 回绕。

## B. 窗口交互

- [x] 点击变频器、TX 阵列、RX 阵列状态项分别打开独立温度曲线窗。
- [x] 三个窗口可同时显示；同一部件重复点击复用并激活原窗口。
- [x] 初始位置靠近对应状态项并限制在可用屏幕范围内。
- [x] 每个窗口支持原生最大化、最小化和关闭。
- [x] 关闭或打开曲线窗不会发送设备命令或改变订阅状态。
