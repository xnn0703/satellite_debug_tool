# M19-A.6 单设备自动报告验收标准

- [x] 单设备和双设备批次均生成 `日期/型号/SN/批次` 目录。
- [x] PASS/FAIL 生成 V1 DOCX；INCOMPLETE/ABORTED 只有 ZIP 与 manifest。
- [x] 每个证据 ZIP 含设备、夹具和测试三类固定路径，并保留批次/会话/时间信息。
- [x] manifest 中 ZIP、DOCX 及 ZIP 内文件 SHA-256 可复算一致。
- [x] 审核人、时间、原结论、最终结论和原因持久化；V2 不覆盖 V1。
- [x] 报告生成失败不改变自动测试结论，并可从冻结快照重试。
- [x] 公司、Logo、页眉、页脚和角色可配置；未配置时报告显示“未配置”。
- [x] 配置包导入导出保留工作站报告品牌字段。
- [x] DOCX 为中文 A4 纵向，包含封面、摘要、配置、结果、完整性、审核和技术附录。
- [x] DOCX 经 LibreOffice 渲染和逐页图片检查，无截断、重叠或不可读表格。
- [x] 有有效 SDB 时生成全程 SNR 与姿态曲线，曲线时间范围、样本数和统计量可由原始记录复算。
- [x] 每个 attempt 显示对应时间窗、阶段统计和结论；无阈值时结论明确为趋势描述/待判定。
- [x] MS6222 同期有效数据存在时生成参考姿态、误差和收敛/发散分析；缺失时明确说明不可作姿态精度结论。
- [x] `evidence.zip` 包含冻结的 `analysis/analysis.json` 和报告使用的曲线图片。
- [x] 含曲线的长报告完成 DOCX 渲染逐页检查，图例、坐标、分页和中文说明清晰。
- [x] 报告按静态、锁定后摇摆、摇摆中上电、车载动态四个一级工况组织，车载动态保留两个子场景。
- [x] 每个启用工况使用自己的 attempt 时间窗生成裁剪曲线、统计分析和结论；全程图只作总览。
- [x] 未启用工况和已启用但缺少时间窗/曲线的工况具有不同且明确的状态说明。
- [x] GNSS、IMU、外部 INS 和整机导航保留为跨工况汇总，不与工况混为同一分类。
- [x] 封面符合参考正式报告层级，包含右上报告编号、居中标题、产品信息、编写/审核/批准签署表和成文日期，且无大号结论占据视觉中心。
- [x] 正文具有独立“测试环境”小节；自动环境信息准确，未配置或未采集的地点、温湿度明确标记。
- [x] 新封面和测试环境加入后重新完成整份 DOCX 逐页渲染检查，封面比例、表格边界、分页和四类工况曲线正常。
- [ ] Windows 打包产物在无 Microsoft Word 环境完成报告生成冒烟测试。
