# M47 验收标准

状态：用户已确认，计时与 SNR 判据按 2026-10-30 用户补充更新。

1. 启动回归：模拟工位就绪、终端初始离线；点击开始先执行电源准备与回读，再等待合法设备，最终冻结参与者并发出首个测试请求。旧链路稳定复现停留待执行，新链路通过。
2. 顺序与事实：启用的首轮台架测试按配方推进；每次硬件动作有所属 owner 的证据；失败或缺失证据时显示具体原因。固件/参数不符产生明确结果，逐设备结论独立记录。
3. 计时：可控时钟验证准备与工况计时独立，配方 1800 秒对应固定 30 分钟；初始搜星包含在工况总时间。初次搜星由同帧有效的 LOCKED 阶段、locked=True 和正 SNR 确认完成；此前初扫/精扫的归零不判失败，完成后的零值/负值永久判该设备失败，后续恢复维持失败记录；所有样本在 UI 两次刷新之间仍逐帧判定。数据缺口保持窗口继续并产生 INCOMPLETE；到零仍须硬件收尾和逐设备分析。
4. 呈现：摘要同时显示测试名称、阶段、步骤序号、已用时和固定工况剩余时间；等待时显示原因。表格当前行与设备卡片和领域快照一致；设备卡片显示正 SNR 时长、已经发生的失败或证据缺口。
5. 多设备：达到冻结数量与身份准入后开始；每台有效窗口与结果可追溯，共享硬件故障影响所有相关参与者。后到设备保持独立状态。
6. 生命周期：切换/隐藏页面持续执行；恢复显示最新状态。中止、断线、设备重启和退出覆盖受控收尾，失效操作范围得到清理。
7. 证据与报告：步骤状态、计时窗口、硬件回执、结果和批次最终状态一致；未完成工况保留明确状态。
8. 质量：新增根因回归、检查相邻启动入口、相关及全量 pytest、翻译 update/check；对照计划记录完成项与剩余现场验收。
9. 现场验收：独立验证真实电源设参/输出、平台动作、MS 参考、终端重启和有效观察时间；软件测试结果单独报告。

10. 手动中止：点击后立即显示正在中止，Qt 事件循环持续响应；倒计时及后续动作停止。周期刷新保持中止状态；电源回读与线程退出无论先后均完成同一请求；慢速运动收尾不阻塞界面；关闭失败显示具体原因；READY、上电准备、等待设备和 RUNNING 均可中止。

11. 创建批次时允许设备断电，包括目录中已有历史身份的离线设备；只冻结配置并保留录制意图。普通遥测不替代身份授权；新有效身份到达后建立录制。共享 Runtime 的不同报文消费顺序都保存首身份帧一次，真实录制失败仍阻止参与者准入。
12. CONFIGURED 工位可以进入自动准备，无需先人工打开调试页。电源按产品电压及设备数量汇总电流设参；台架工况自动连接所选平台和参考串口。取得平台动作回读和有效参考帧之后才运行工况计时；租约冲突报告实际 owner。

13. 搜星边界回归：ACQUIRING 与 FINE_TRACKING 中的正值/零值交替保持初始搜星，不产生失败；正式 LOCKED 后的归零永久保留失败，即使随后重捕恢复。未知阶段、缺失有效位、阶段与锁定标志不一致均不确认初次完成；缺少阶段证据的完整窗口为 INCOMPLETE。单台掉锁后不回显示初始搜星，多设备卡片分别呈现自己的真实阶段。锁定后摇摆入口同样消费明确的设备锁定事实。

## 2026-10-30 MS 精度提示调整验收

- 标准差超过1°、8°及无效标准差不阻止当前 SNR 工况启动、动态上电或计时；原始数据和精度告警保留。
- 渐入后真实运动反馈仍是动态启动条件；静置回中和电源回读条件保持。
- 运行中 MS 标准差恶化后，SNR 正值窗口可正常通过；SNR 归零仍失败。
- MS 断连、有效姿态帧过期/无效与运动反馈异常保持现有处理。
- 不改变工位阈值数值，不宣称参考姿态精度合格。
