# v1.5.0 Windows 发布说明

## 主要更新

- 摇摆台档案删除无供应商依据的单步角度限制，合法绝对位姿改为每次只发送一条 A6T 指令。
- 三轴轨迹使用单调时钟绝对期限调度，默认 `50 ms`，最低允许 `20 ms`；发生完整周期超期时停止后续指令并记录 timing fault。
- 正弦轨迹预检加入渐入、渐出包络的速度和加速度约束。
- 摇摆台测试页面接入 MS-6222 串口状态、姿态质量和联合证据采集。
- 新增一键自动资格测试：依次执行中心、Roll/Pitch/Yaw 正负 `3°` 和最终回中，并记录响应延迟、上升时间、稳态误差、方向映射及交叉耦合。
- 完成安全确认并选择串口后，单击自动测试即可自动打开 MS-6222、等待有效姿态帧并建立工程证据会话。
- 自动测试结束生成自包含 `*-diagnostics.zip`，用于现场回传和后续精度阈值分析。

## 现场验证边界

- 首轮自动资格测试结论保持 `INCONCLUSIVE`；方向映射、动态响应和精度阈值须根据真实摇摆台与 MS-6222 证据冻结。
- MS-6222 当前作为独立测量参考，不参与摇摆台控制输出；反馈外环需要另行验证固定延迟、频响、稳定裕度和异常退出。
- `20 ms` 指令周期已通过软件预检和调度回归，尚未完成厂家服务程序与真实平台的持续运行验证；现场先使用默认 `50 ms`。
- MS-6222 不承担限位、急停或人员安全功能，现场硬件保护和安全确认继续生效。
