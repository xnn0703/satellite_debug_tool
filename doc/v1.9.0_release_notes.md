# 卫通终端管理工具 v1.9.0

英文名称：Satellite Terminal Manager。提供 Windows x86_64、macOS Apple Silicon 的用户版和运维版完整包。

## 自动化测试与证据

- 创建批次允许设备断电；开始后按所选工位和型号自动准备电源、摇摆台及姿态参考。
- 当前阶段、启用的测试节点和倒计时置于曲线上方；按实际设备数量显示曲线，夹具状态用指示灯呈现。
- 手动中止进入统一收尾流程；处理 MS-6222 与被测设备共享电源的动态上电场景。
- 搜星阶段与正式观察分开记录，按用户确认的 SNR>0 和配方时长判定；缺失证据明确记为未完成。
- 内置 AFD01B2/C/D 的 12 V 9 A、24 V 5 A 型号预置，保留自定义和导入入口。
- 自动化录制与报告保存完整配置、事件和质量信息，默认沿用设置的录制根目录。

## 界面与连接

- 正式名称统一为“卫通终端管理工具 / Satellite Terminal Manager”，应用名称不带版本后缀。
- 改进断连布局、Shell 退出收尾及页面切换期间的录制生命周期。
- 客户侧电源由显式连接意图启动，避免抢占自动化测试的电源控制。

## 更新与分发

- Windows 由 GitHub Actions 构建，Mac 本机构建，候选自动上传阿里云。
- 用户版提供完整包人工交付，关闭应用在线更新；设备固件升级功能保留。
- 运维版使用 HTTPS 与签名元数据检查更新；Windows 同盘安装、健康回执及故障恢复共用一条事务路径。
- Windows 支持上一正式基线的文件级差量，适用性或验证失败时转用完整包。本版是新更新仓库首个完整版本，没有差量基线。
- Mac 运维版校验下载完整 ZIP，退出应用后手动替换。

## 安装说明与边界

- 从 v1.8.1 及以前版本首次迁移：下载对应完整包，退出旧程序，将完整新目录/应用放到独立位置启动；后续运维版使用新站点更新。不要将新文件混合覆盖到旧目录。
- Windows 运行 SatelliteTerminalManager.exe；Mac 将 SatelliteTerminalManagerUser.app 或 SatelliteTerminalManagerOps.app 放入 Applications。
- 内部配置目录和应用身份保持，已有设置/录制数据继续按原路径读取；user 与 ops 配置相互独立。
- 本次 Mac 为 Apple Silicon 构建，最低声明 macOS 14；Windows 为 x86_64 构建。
- 软件测试、冻结启动和下载校验结果在发布记录中单列；Windows 实机升级恢复与真实硬件测试保持独立验收。
