# M19-A.11 灵境运动平台直接控制组件开发记录

## 当前状态

- 状态：软件实现完成，等待 Windows 打包与真机分级验收
- 实施范围：直接控制组件、档案 v4、夹具线程/UI、诊断证据、旧厂家服务移除、翻译与自动化回归
- 依据：M19-A.10 静态分析、现场抓包分析、供应商上位机正常/越界/断网/回原点/物理急停证据

## 已冻结的设计决策

- 采用独立 `core/motion_platform/` 组件，界面和试产编排不直接访问协议与 socket。
- 直接控制组件是运动平台唯一 owner；完成结论来自控制器反馈闭环。
- 运动学使用整条严格拒绝，删除逐轴钳位。
- MS-6222 保持独立，上层按测试场景组合。
- 物理急停是当前唯一已证明的紧急停止通道。
- 直接控制链路验收后删除厂家服务活动路径和发行资源。
