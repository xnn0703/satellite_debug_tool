## E. 正式自动化执行器

- [ ] 批次只有一个 `ProductionRunCoordinator` 推进 attempt 和共享夹具动作。
- [ ] 首轮自动完成固件、参数、静态捕获、锁定后摇摆、摇摆中上电、回中和断电。
- [ ] 电源开启前确认输出关闭、身份匹配、设定值和保护状态。
- [ ] 平台运动前确认中心、MS 参考有效、设备录制和参与者冻结。
- [ ] 摇摆中上电明确记录断电、动态轨迹、供电、DUT 新启动实例、收敛和重新锁定。
- [ ] 同一共享动作只保存一次，并被每台参与设备 attempt 引用。
- [ ] 单台设备失败不覆盖其他设备结论；共享夹具失败使相关窗口 `INCOMPLETE`。
- [ ] 台架动态模拟与真实车辆人工工况在状态、报告和证据中使用不同名称。
- [ ] 完成或中止均执行受控停止、回中策略、电源关闭验证、证据收尾和 owner 释放。
