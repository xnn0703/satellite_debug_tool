# M19-A.3 PSW 电源独立调试页验收标准

## A. 页面与所有权

- [x] Production Workspace 显示“批次测试 / 夹具调试 / 电源调试”三个二级页面，电源页首次访问才构建。
- [x] 电源调试无需批次、配方、DUT 或摇摆台档案。
- [x] 批次、摇摆台工程会话和电源连接不能同时持有共享夹具控制权。
- [x] 输出已确认开启或状态未知时，离开页面、断开连接和关闭应用均显示当前事实，不把 TCP 断开描述为电源关闭。

## B. 配置门禁

- [x] IPv4、端口、厂家、型号、可选 SN、需求电压、电流和超时均有明确输入字段；验证限制只读显示。
- [x] 端口可预填 `2268`，厂家/型号可预填 `GW-INSTEK / PSW 80-27`；电压和电流没有 14 V/2 A 或其他隐式默认值。
- [x] 设定值读回容差、开启窗口和关断门限由 PSW80-27 单一验证策略自动计算，操作者不能输入互相矛盾的限制。
- [x] 电压、电流未完整、非有限、非正、超出额定范围或乘积超过 720 W 时拒绝连接和写操作。
- [x] 页面不提供任意 SCPI 命令输入和自动循环 OUTPUT ON。

## C. 只读连接与状态

- [x] “连接并识别”只执行 `*IDN?`，身份不匹配时关闭 TCP 并明确原因。
- [x] “读取状态”只执行 `OUTP? / MEAS:ALL? / STAT:OPER:COND? / STAT:QUES:COND? / OUTP:PROT:TRIP?`。
- [x] 页面显示身份原文、厂家、型号、SN、固件、连接代次、逻辑输出、实测电压、总电流、状态字和保护状态。
- [x] 读取失败使状态进入 `UNKNOWN`，不保留旧的在线或输出结论。

## D. 写操作闭环

- [x] “应用参数并确认 OFF”先在稳定期限内确认输出关闭和电压下降，再设置电压、电流并核对 `*OPC?`、设定值读回及错误队列；全部满足后才进入 `READY_OFF`。
- [x] “开启输出”在身份已验证后可用，一次确认自动完成 OFF 准备和 OUTPUT ON；确认框显示电压、电流和自动允许窗口。
- [x] 只有 `OUTP?=1`、实测电压进入允许窗口且无保护/告警时，状态显示“输出已确认开启”。
- [x] “关闭输出”连接存在时始终可请求；只有 `OUTP?=0` 且实测电压不高于断电门限时，显示“输出已确认关闭”。
- [x] `SYST:COMM:RLST LOC` 只显示“已请求返回本地控制”，不改变或推断输出状态。
- [x] 重连只做身份识别，不重放设定值、OUTPUT ON 或上次动作。

## E. 线程、生命周期与证据

- [x] 所有 TCP 操作在单一后台执行上下文中串行运行，UI 不阻塞且不存在并发读取。
- [x] 操作期间按钮状态与 adapter 状态一致，重复点击不会创建并发动作。
- [x] 会话目录保存配置快照、身份、完整 SCPI 记录、操作结果、事件和最终状态，并标记 `ENGINEERING_ONLY`。
- [x] 正常断开、网络失败、应用退出和后台异常均关闭 worker/transport；无法确认最终状态时会话为 `INCOMPLETE`。
- [x] 中英文切换后动态状态与按钮文案正确；1024x600 和 1280x800 下主要控件可达。

## F. 自动化验证

- [x] 脚本化 transport 覆盖连接成功、身份拒绝、只读状态、OFF 预检、开启、关闭、保护触发、设定值不符、超时、断线和重连不重放。
- [x] Production Workspace 测试覆盖第三页懒加载、页面切换和共享租约互斥。
- [x] `python3 scripts/update_translations.py update` 与 `check` 通过，TS/QM 同步。
- [x] 全量 `PYTHONPATH=. pytest satellite_debug_tool/tests -q` 通过且无新增 warning。

## G. 真机工程验收

- [ ] 使用真实 PSW 完成身份识别和只读状态检查，证明连接动作没有改变输出。
- [ ] 在输出 OFF 下完成设定值写入、读回、错误队列和保护状态检查。
- [ ] 在经批准的电压、电流、负载、支路保护和实体安全措施下，完成一次 OUTPUT ON、电压确认和 OUTPUT OFF、电压下降闭环。
- [ ] 身份不匹配、TCP 断线和应用重启均不会自动开启输出。
- [ ] 现场核对会话记录与电源面板、实测电压及人工观察一致。

> 本页面通过后仅表示 PSW 独立工程控制链可用，不表示 M19 批次自动流程、单机功耗测量或正式试产放行完成。
