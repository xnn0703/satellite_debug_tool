## 2026-10-08：实现结果

- `FixtureAxisLimits`、`MotionPlatformConfig`、档案 JSON 和安装配置界面均删除单步角度；合法 v1/v2 档案先校验原始 SHA-256，再迁移到 v3。
- `AbsoluteMoveRunner` 对单轴、组合位姿、回中和复位各发送一条 A6T，并保持 busy 到计划完成时刻。
- 正弦轨迹从下一采样时刻开始下发，使用绝对单调 deadline；跨越完整周期时形成 timing fault 并停止后续指令。
- 速度和加速度预检加入 `sin²` 渐入/渐出包络的一阶、二阶导数上界。
- 灵境预设最短完成时间调整为 `20 ms`，界面默认采样周期为 `50 ms`；`20 ms` 仍等待真机资格验证。
- 新增 `FixtureQualificationController`，自动执行中心、三轴正负 `3°`、中心复核，输出建议坐标映射、方向、交叉耦合、噪声、响应延迟、上升时间和稳定窗口误差。
- 有确认标定时精度指标使用确认标定；无确认标定时使用本次自推导映射并明确标记 `SELF_DERIVED_ENGINEERING_MAPPING`，结论保持 `INCONCLUSIVE`。
- 自动流程生成完整 fixture session，并在相邻路径生成 `*-diagnostics.zip`。
- 自动测试入口自动打开所选 MS-6222 串口、等待首个有效姿态帧并建立工程证据会话，保留用户取消入口。
- 翻译目录 `1335` 条全部完成且 TS/QM 同步。
- 定向回归 `44 passed`；最终全量回归 `1426 passed`。未执行摇摆台、MS-6222 和急停真机验收。
