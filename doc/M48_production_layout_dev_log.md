## 对照计划的实现

| 计划 | 实现与事实来源 |
| --- | --- |
| 实际设备曲线 | `presentation.chart_slots` 使用冻结参与身份和真实槽位，冻结前按目标数量选择候选并独立等待占位。单台全宽，双台并排，三台第三张跨两列，四台双列；窄窗单列。控件按真实槽位保留实例，重排不重绑 endpoint。 |
| 横向流程 | `enabled_production_tests` 唯一投影正式启用项、必需入口和派生汇总，节点结论读取 ResultStore attempts；删除旧表格与其状态字典。节点分母包含本批次实际显示的汇总项目。 |
| 阶段与时间 | `ProductionProgressPanel` 消费 M47 快照，不创建业务计时器。准备、搜星、观察、收尾与结束都有直接状态；中止/INCOMPLETE 重复刷新保持清空旧钟。 |
| 夹具灯 | FixtureRuntime 统一拥有 power/motion/reference/vehicle 事实；配方相关性决定灰色，READY/RUNNING 绿色，CONFIGURED/连接/故障红色。可通过鼠标或键盘查看证据，回读关闭后电源恢复配置状态。 |
| 精简配置与事件 | 输出目录、端点、电气需求、完整 SHA-256 收进可展开配置详情；最新事件摘要常显，完整日志可展开。批次创建后目录刷新和程序信号均保留冻结内容。 |
| 固定操作与响应式 | 底部中止/报告操作位于滚动内容之外。图卡保持 180 px 最小高度，小窗口图表区纵向滚动；展开配置/日志后内容可滚动，操作仍固定。 |
| 主题与语言 | 复用用户页 `S.palette`、字体和 QSS；节点、灯、设备默认状态持稳定 source key，切换语言从领域/Store 重绘，保持准备和终态。 |
