# 卫通终端管理工具 v1.9.11

发布日期：2026-11-14

本版用于验证 v1.9.10 之后的 macOS 与 Windows 运维版自动更新闭环。应用业务功能保持不变，发布链路采用 M71 ECS 本机候选晋升模型。

## 自动更新验证

- macOS 运维版从真实 `Contents/Resources/satellite_debug_tool/build_identity.json` 读取构建身份，下载后由持久 updater 完成退出、替换、重启、健康确认与失败回滚。
- Windows 运维版继续使用同一更新请求、journal、完整包校验、安装事务和回滚合同。
- 两个平台进入同一份 TUF publication，经一次 timestamp 原子切换同步发布。
- 本版未生成差量包，运维版自动更新会下载经过签名目录和 SHA-256 校验的完整安装包。

## 发布链路

- Windows 候选由 GitHub Actions 构建，macOS 候选由发布 Mac 本地构建。
- ops 大包只上传一次到 incoming；ECS 在服务器本机复制为独立公开文件并执行完整 SHA-256，发布机随后执行 HTTPS Range 复核。
- user 版不启用应用自动更新，继续通过服务器完整安装包人工交付。

## 发行边界

- macOS arm64 仍为 ad-hoc 签名，未执行 Apple notarization。
- 软件测试、构建、候选回执和归档校验不替代 Windows/macOS 实机安装回滚、真实设备、RF、供电、摇摆台或车辆现场验收。
