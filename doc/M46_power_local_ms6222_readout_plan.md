# M46 电源返回本地与 MS-6222 姿态对照计划

日期：2026-10-30。用户已确认实施。源码与专项回归已完成，全量复测与现场验收状态见 acceptance/dev_log。

## 1. 需求与代码事实

1. 客户外接电源窗口提供设参、读状态和输出启停，缺少退出遥控入口。`GwInstekPswAdapter.release_local()` 已提供 `SYST:COMM:RLST LOC`，试产电源调试已有调用；客户 `PswControlledSession` 和 `ExternalPowerWorker` 尚未接入。现有 close 只关闭 TCP；worker 还有轮询与自动重连，因此交还面板需要完成整个监测会话的受控释放。
2. 客户总览 `CustomerOverviewView._refresh_model()` 只向 3D 控件提供设备姿态。`FixtureRuntime` 已拥有进程级 MS 串口租约和姿态总线；现有总线含标定后相对 FRD、真实航向，独立 MS 调试页的原始 INS 姿态尚未统一发布。需要补齐共享事实来源，再增加一行呈现。
3. 当前工作树包含 M26/M43/M44/M45 等未提交修改。本轮基于现有工作树，保留这些修改。

## 2. 交付行为

### 电源

- 外接电源页增加“退出遥控（恢复面板）”。由当前 worker 串行停止后续采样与动作，发送返回本地命令，关闭 TCP 并停止自动重连；再次“保存并连接”才恢复监测。
- 操作保持当前输出与电压/电流设定值；历史曲线保留。释放期间阻止新增控制动作，并明确完成或失败状态。
- 仅有写入证据时显示“已发送返回本地指令，监测已停止”；通信失败显示“面板控制待确认”，不能显示已恢复手动。
- 明确处理正在连接、读取失败、存在排队动作、重复点击、设备切换与退出收尾。后台状态变化采用同一会话 owner，防止旧信号恢复 ONLINE 或触发重连。
- 本轮明确按钮执行交还；关闭曲线窗口继续遵循现有后台监测生命周期。应用退出、配置切换等相邻入口检查并记录其控制权释放语义。

### MS-6222

- 在客户总览 3D 当前设备姿态数字下方增加一行 `MS-6222` 的 Roll / Pitch / Yaw，顺序、单位与设备行一致。
- 通过进程级 FixtureRuntime/Store 提供单一参考快照。独立 MS 页面与摇摆台入口都向此来源发布；总览只读取，不再开启串口。
- 2026-10-30 用户确认修正：总览固定呈现 MS INS 原始横滚/俯仰与绝对航向，角度显示三位小数；摇摆台按安装标定呈现相对 FRD 姿态。两条用途分别拥有确定来源。示例：原始航向 158.468°、标定相对航向 5.017° 时，总览显示 158.468°。
- 已连接但尚无有效 INS 帧时显示“等待姿态”；断开、数据过期、质量无效时清除实时数字并呈现对应状态。新会话清除旧会话参考。
- 尚未使用 MS 时隐藏附加行；已建立参考会话后保留状态提示。新增一行不驱动 3D 模型，不增加误差/PASS 判定。
- 隐藏页面停止刷新；重新打开立即读取最新快照。运维版装配参考能力，用户版遵循既有模块边界。
