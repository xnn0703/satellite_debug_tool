# v1.4.0 Windows 发布说明

## 主要更新

- 增加 AFD01A、AFD01B2 独立产品身份、客户工作区、试产模板和固件包准入支持。
- 试产配置改为直接选择产品型号、设备数量、电源型号和工作站档案，并支持配置导入导出。
- 每台设备生成独立中文 Word 报告、证据 ZIP、SHA-256 manifest，并支持 V2 审核。
- 报告按静态、锁定后摇摆、摇摆中上电和车载动态工况组织曲线、分析和结论。
- 摇摆台档案改为型号选择，当前南京灵境 200 mm 六自由度平台自动生成通信和运行参数。
- Windows 版随附并自动托管灵境 `ProConvert.exe + StewartPlat.dll`：进入摇摆台测试后自动部署、最小化启动并确认 UDP 9800 监听。
- 摇摆台页面新增诊断包导出，包含应用日志、厂家日志、配置、网络快照和逐文件 SHA-256。

## 现场验证边界

- Windows 上位机有线网卡配置为 `192.168.15.101/24`，底层控制器地址为 `192.168.15.201`。
- 厂家服务要求 Microsoft .NET Framework 4.8。
- UDP 9800 监听表示服务进程已就绪；真实运动仍需通过低幅动作、现场观察和 MS-6222 证据确认。
- 当前摇摆台机械和换算参数使用用户确认的原始 `plat.xml`，SHA-256 为 `eaead18830af2ce2799c73f47d7197954eb26b02f8d95c616949203ec190d761`。
