## 1. 项目概述

### 1.1 目标

开发一款用于调试相控阵卫星通信设备的桌面调试工具，实现设备数据的实时显示、曲线绘制、数据录制与回放。

### 1.2 数据来源

| 类型 | 说明 |
|------|------|
| 通信协议 | DEBUG设备协议（二进制格式） |
| 传输方式 | 串口（默认）、UDP、TCP |
| 数据频率 | 最大 200Hz |
| 通道数量 | 1-16 个通道 |

### 1.3 典型数据

| 数据类型 | 示例 | 用途 |
|----------|------|------|
| GPS数据 | 经度、纬度、高度 | 位置显示 |
| 姿态数据 | Roll、Pitch、Yaw | 方向指示 |
| 信噪比 | SNR | 信号质量 |
| 波束指向 | Azimuth、Elevation | 指向控制 |

## 4. 功能规格

### 4.1 通信连接

#### 4.1.1 串口连接

| 参数 | 默认值 | 可选值 |
|------|--------|--------|
| 波特率 | 115200 | 9600, 19200, 38400, 57600, 115200, 230400, 460800, 921600 |
| 数据位 | 8 | 8 |
| 停止位 | 1 | 1 |

| 流控制 | 无 | 无 |

**连接流程**：
1. 用户选择串口号
2. 配置波特率（可选）
3. 点击连接
4. 状态栏显示连接状态

#### 4.1.2 UDP 连接

#### 4.1.3 TCP 连接（暂不实现）

预留接口，暂不实现。

### 4.2 数据解析

#### 4.2.1 帧解析流程

```
字节流 → 搜索帧头(0xAA 0x55) → 读取设备类型 → 读取命令类型 → 读取数据长度 
→ 读取数据 → 读取CRC → 读取帧尾(0xEE) → CRC校验 → 解析数据
```

#### 4.2.2 CRC16-CCITT 校验

| 参数 | 值 |
|------|------|
| 多项式 | 0x1021 |
| 初始值 | 0xFFFF |
| 计算范围 | 帧头到数据部分（不含CRC和帧尾） |

### 4.3 实时显示

#### 4.3.1 曲线显示

| 项目 | 规格 |
|------|------|
| 最多显示通道 | 16 个 |
| 显示模式 | 滚动时域图（时间轴向右滚动） |
| 时间窗口 | 可配置，默认 10 秒 |
| 坐标轴 | X轴=时间，Y轴=通道值 |
| 网格 | 半透明网格线，便于读数 |
| 曲线宽度 | 1.5px |

#### 4.3.2 数据显示

每个通道同时显示：
- 通道名称
- 当前值（数值）
- 最新值标注在曲线末端

#### 4.3.3 通道控制

- 复选框勾选显示/隐藏
- 最多同时显示 8 条曲线（避免混乱）
- 隐藏的通道继续录制

### 4.4 数据录制

#### 4.4.1 录制格式

**二进制格式 (.sdb - Satellite Debug Binary)**

| 字段 | 长度 | 说明 |
|------|------|------|
| 文件头 | 16字节 | "SDB\0" + 版本号 + 保留 |
| 帧头 | 4字节 | 0xAA 0x55 0xAA 0x55 |
| 帧数据 | 可变 | 原始帧（不含文件帧头） |
| ... | ... | 重复 |
| 文件尾 | 4字节 | 0xEE 0xEE 0xEE 0xEE |

#### 4.4.2 录制控制

| 操作 | 说明 |
|------|------|
| 开始录制 | 创建新文件，写入文件头 |
| 停止录制 | 写入文件尾，关闭文件 |
| 录制中状态 | 状态栏显示录制时长 |

### 4.5 数据导入与回放

#### 4.5.1 支持格式

| 格式 | 说明 | 优先级 |
|------|------|--------|
| .sdb | 私有二进制格式 | 必须 |
| .csv | 逗号分隔文本 | 高 |

#### 4.5.2 CSV 格式

5,31.2305,121.4738,10.6,0.1,0.2,-0.3,35.3,45.1,60.1
...

#### 4.5.3 回放控制

- 播放/暂停
- 速度控制：0.5x, 1x, 2x, 4x
- 进度条拖动跳转
- 停止后退出回放模式

### 4.6 告警功能

## 6. 异常处理

### 6.1 通信异常

| 异常 | 处理方式 |
|------|----------|
| 串口不存在 | 弹窗提示，刷新串口列表 |
| 串口被占用 | 弹窗提示 |
| UDP 绑定失败 | 弹窗提示，状态栏显示错误 |
| CRC 校验失败 | 丢弃帧，计数器+1，状态栏警告 |
| 帧格式错误 | 丢弃帧，计数器+1，同步搜索下一个帧头 |

### 6.2 数据异常

| 异常 | 处理方式 |
|------|----------|
| 通道数超限 | 丢弃超限通道，只处理前16个 |
| 通道名过长 | 截断为31字符 |
| 值为 inf/nan | 丢弃该帧，不更新曲线 |

### 6.3 录制异常

| 异常 | 处理方式 |
|------|----------|
| 磁盘满 | 停止录制，弹窗警告 |
| 写入失败 | 停止录制，弹窗警告，保留已录制数据 |
