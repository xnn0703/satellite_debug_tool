# M19-A.14 客户页面组合连续摇摆验收标准

## A. 界面

- [x] 客户摇摆台弹窗显示 Roll/Pitch/Yaw 组合正弦参数、时长和采样周期。
- [x] 支持任意单轴、双轴和三轴组合，至少选择一轴。
- [x] 支持预览校验、开始组合摇摆和受控停止。
- [x] 客户模式继续隐藏回原点、资格测试、坐标标定和档案编辑。
- [x] 语言切换后客户模式文案保持正确。
- [x] `Ctrl+Shift+E` 工程工作区顶栏可以打开同一个摇摆台控制弹窗。
- [x] Customer 与 Engineering 不会创建两个弹窗实例或两套物理控制 owner。
- [x] 姿态区域只有一张共享坐标图，九条曲线能按轴颜色和数据线型辨认。
- [x] 合并图保留断帧间隙、角度单位、会话时间和五分钟滚动窗口。

## B. 安全与执行

- [x] 未连接、未开始控制会话或安全确认不完整时不能启动轨迹。
- [x] 完整轨迹在发送前通过角度、频率、速度、加速度、运动学和执行器范围校验。
- [x] 运行中不能重复启动轨迹或发送点动命令。
- [x] 受控停止后不再发送后续目标点，不自动恢复。
- [x] 调度过期点只跳过并记录，不补发。
- [x] 客户与 Production 使用同一摇摆台租约，不能并发控制。

## C. 姿态与证据

- [x] 曲线显示目标姿态、标定后的 MS-6222 相对姿态和三轴误差。
- [x] MS-6222 绝对航向继续单独显示，不作为相对 Yaw 命令。
- [x] 轨迹摘要记录计划点、发送点、跳过点和最大迟到。
- [x] 正常完成、受控停止、断线和证据失败能够区分。
- [x] 连续轨迹不会因为启用静态有界修正而逐帧生成闭环命令。

## D. 自动化验证

- [x] 客户模式可见性和客户文案有 UI 回归。
- [x] 单轴、双轴、三轴预检及非法配置有回归。
- [x] 运行互斥、受控停止和调度跳点有回归。
- [x] 翻译 update/check 通过（1358 条文案）。
- [x] 全量测试通过（1436 passed）。

## E. 真机验收

- [ ] Roll 单轴小幅低频连续运行和停止正常。
- [ ] Roll/Pitch 双轴组合连续运行和停止正常。
- [ ] Roll/Pitch/Yaw 三轴组合连续运行和停止正常。
- [ ] MS-6222 曲线方向、幅值和相位与目标一致，无错误轴映射。
- [ ] 轨迹完成后平台停止，执行器保护判断与 MS 姿态结论分别显示。
