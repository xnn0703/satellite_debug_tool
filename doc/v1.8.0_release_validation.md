## Windows 诊断结论与发布门禁修订

- 40289706086 证明源码同样发生 OpenGL 1282：Qt 上下文 3.0，进程同时加载 Qt 的 opengl32sw.dll 与系统 opengl32.dll；Qt 动态软件后端与 PyOpenGL 的系统调用路径不一致。强制 desktop 在该 Runner 崩溃，不能把该虚拟环境当作目标显卡渲染验收。相关 Qt 合同见 https://doc.qt.io/qt-6/windows-graphics.html 。
- 离屏路径完成页面/模型/Shell/关闭并输出完整 PASS，随后因日志文件仍打开，Windows 无法清理临时目录。增加旧实现稳定失败的日志占用回归，收尾先关闭 logging，再清理临时目录。
- CI 明确采用离屏 Qt 验证资源/装配/退出，普通程序保留原图形行为；真实 Windows 3D 及旧安装升级保持现场边界。移除本轮临时图形对照工作流，保留可复用的冻结失败证据设施。
- 发行流水线先生成草稿；本地和下载资产校验完成后再发布，保证未通过门禁的版本保持草稿状态。
