# M19-A.5 摇摆台与 MS-6222 独立调试计划

## 目标

将当前“夹具调试”页面拆成两个明确入口：

- **摇摆台测试**：只负责灵境 A6/A6T 运动控制、安全门禁、轨迹调度和命令证据。
- **MS-6222 测试**：只负责串口连接、协议识别、报文质量、姿态/GNSS/原始 IMU 展示和独立采集证据。

操作者可以在没有摇摆台、DUT、批次或电源的情况下单独验证 MS-6222。正式批次仍可同时使用两者，并通过统一单调时间关联平台命令与参考姿态。

## 当前事实

- 摇摆台控制使用 UDP，MS-6222 使用独立 USB-RS422 串口 worker，底层协议和线程已经分离。
- 当前 `FixtureDebugWorkspace` 同时持有平台控制、MS 串口、联合记录、标定和姿态比较，造成操作入口和会话语义耦合。
- 当前无 MS 时已经允许发送摇摆台命令，证据最高为 `COMMAND_SENT`。
- MS-6222 不参与摇摆台实时伺服、安全限位或急停，只提供独立参考测量。
- 同一物理串口必须只有一个 owner；不能让独立测试页和正式批次同时各自创建 worker。

## 页面结构

Production Workspace 顶部改为四个入口：

1. 批次测试
2. 摇摆台测试
3. MS-6222 测试
4. 电源测试

原“夹具调试”入口改名为“摇摆台测试”。日常摇摆台操作不再出现 MS 串口连接、报文统计和参考传感器状态。

## MS-6222 独立测试页

### 1. 连接与身份

- 列出可用串口，默认 `460800 8N1`，支持刷新、连接和断开。
- 连接只表示串口已打开；收到并通过 CRC 的合法帧后才显示“有效数据已确认”。
- 自动识别 INSPVAXB、GNSS v1/v2 和 RAWIMUSB，不增加手工协议选择。
- 显示最近数据时间、协议版本、各帧计数/频率、CRC 错误、无效长度、噪声丢弃量和串口错误。

### 2. 实时数据

- 显示 Roll/Pitch/Yaw、INS 状态、时间状态、姿态标准差和 GPS 时间。
- 显示 GNSS 位置、速度、解状态、卫星数和差分状态。
- 显示 RAWIMUSB 三轴角速度、加速度和温度字段。
- 独立绘制最近五分钟姿态曲线；绘图限频不影响原始帧记录。

### 3. 独立采集会话

- 无需夹具档案、摇摆台、安全确认、批次或 DUT 即可开始。
- 会话保存到 `~/.satellite_debug_tool/ms6222_sessions/<session_id>/`。
- 至少保存配置快照、原始帧 JSONL、解析 CSV、统计快照、事件、summary 和 manifest SHA-256。
- 操作者可以填写会话名称和备注，结束后得到 `passed / failed / inconclusive` 工程结论；固定标记 `ENGINEERING_ONLY`。
- 断线、CRC 连续异常、写盘失败或进程退出保留已有证据并标记 `incomplete`。

### 4. 验证摘要

页面给出明确、分层的结果：

- 串口已打开。
- 合法帧已确认。
- 三类报文是否到达预期频率。
- 姿态时间状态和 INS 状态是否满足参考采集条件。
- 连续采集时长、数据缺口、CRC 有效率和有效姿态覆盖率。

首版不签发正式参考资格，不自动写 MS-6222 配置，也不将“有数据”描述为“姿态精度合格”。

## 摇摆台测试页

- 保留夹具档案、四项安全确认、单步、回中、显式 Z=0 复位、组合轨迹和命令记录。
- 会话保存平台命令、目标姿态、调度抖动、跳点、发送结果和事件。
- 不连接 MS-6222，不展示实测姿态或误差曲线，不生成姿态精度结论。
- UDP 发送成功仍只表示 `COMMAND_SENT`。

## 联合使用合同

- 独立页面各自验证设备，不互相充当控制前提。
- 正式批次是联合流程的唯一 owner：同时引用摇摆台档案和 MS-6222 参考档案，将两条证据写入同一批次时间线。
- MS-6222 串口使用独占租约。独立测试页占用时，批次不能启动参考采集；批次占用时，独立页不能连接。
- 摇摆台控制继续使用现有夹具独占租约，与批次互斥。
- 现有联合夹具会话保留只读兼容，历史 `fixture_sessions` 不迁移、不改写。
- M19-A9 已实现明确的联合资格测试动作：由摇摆台测试页显式获取平台与 MS-6222 两项租约；独立 MS 页面仍不拥有运动控制入口。

## 实施顺序

1. 提取 MS-6222 独占租约和独立会话记录器，复用现有 parser 与 serial worker。
2. 新增 `Ms6222DebugWorkspace` 和 Production Workspace 顶部入口。
3. 将 `FixtureDebugWorkspace` 收敛为摇摆台单设备测试页，删除其 MS 串口 owner、MS 实时状态和联合指标 owner。
4. 保留历史联合会话读取兼容；把联合标定依赖集中到独立服务边界。
5. 接入主题、运行时翻译、关闭确认和页面生命周期。
6. 补齐独占、断线、坏帧、长时采集、写盘失败、页面切换和 UI 测试。
7. 更新 AGENTS、验收记录并执行全量回归。

## 不在本轮范围

- 不修改 MS-6222 固件或自动下发配置。
- 不用 MS-6222 控制摇摆台，不实现实时姿态闭环。
- 不签发正式参考传感器资格。
- 不实现完整整机工况编排和正式设备报告。
- 不删除或重写历史 `fixture_sessions`。
