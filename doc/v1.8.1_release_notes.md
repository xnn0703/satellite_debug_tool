# v1.8.1 发布说明

本次修复 Shell 高频接收、设备采集时间重新起算及外接电源控制流程，并在运维版总览增加 MS-6222 姿态对照。

## 下载选择

| 版本 | Windows 压缩包 | 用途 |
|---|---|---|
| 用户版 | `satellite_terminal_tool-user-windows-v1.8.1.7z` | 总览、RF 控制、录制/回放、加密固件升级、Shell |
| 运维测试版 | `satellite_debug_tool-win-v1.8.1.7z` | 完整工程诊断、电源、网络、摇摆台、MS-6222、试产工具 |

使用 7-Zip 将两版分别解压到独立目录，运行各自的 `SatelliteDebugTool.exe`。两版配置与更新归属各自独立。

## 主要修复

- Shell 统一处理键盘、输入法提交与粘贴的 ASCII 命令校验，改善跨包光标、退格覆盖、中文日志与正文/HEX 切换。
- Shell 接收采用有界缓冲与按帧呈现，改善大量日志时的输入响应，完善清屏、断开和退出的残余数据收尾；两版共享这条工具路径。
- 设备采集时间重新起算时，统一恢复实时状态与 SNR/温度历史，并使旧操作授权失效；回放按采集段呈现时间与缺口。
- 外接电源轮询保留已经验证的配置事实，开启输出前回读状态；新增“退出遥控（恢复面板）”，发送本地控制指令并停止监测，保留输出设定与历史，再次“保存并连接”恢复远程监测。
- 运维版总览在设备 3D 角度下方显示共享 MS-6222 原始姿态和绝对航向，精度三位小数；数据过期、质量无效或断开时显示对应状态。摇摆台继续使用标定后的相对角度。
- 夹具会话收尾通过主线程槽推进，后台完成耗时证据分析。
- 工程协议增加 `INS_TRACE (0x12)` 原始输入/内部快照解码及 SDB 原始帧保存，供支持该命令的固件诊断使用。

## 验证范围

发布流程验证源码回归、双版装配、冻结程序总览/Shell/受控退出及归档版本身份。Windows 目标机图形驱动和 3D 渲染、现场输入法与连续日志、设备重启恢复、电源面板控制及 MS 安装方向由实际设备验证；指令发送、设备接受与物理动作分别保留证据。

本次提供 Windows 双版发行包。macOS 构建结果用于本地打包验证，单独分发。
