## A. 主题与颜色角色

- [x] A1：`dark` 使用石墨灰表面、蓝色操作/选择及独立状态色，关键数值使用正文角色。
- [x] A2：`light` 使用中性浅灰与白色表面，角色与 dark 对应，文字与图标使用该主题配对。
- [x] A3：`dark_hc` 保留黑底、白色主文字及清晰边界，操作与设备状态可区分。
- [x] A4：主题 ID、现有设置与 `palette()` 有效 API 合同通过回归，三档主题可正常切换。
- [x] A5：当前选择与键盘焦点可同时辨认；hover/pressed/disabled 状态各自清晰。
- [x] A6：背景/文字/状态/选择等应用颜色来自主题中心；被替代的组件局部色表已经清理。
- [x] A7：颜色含透明度时按 Qt 支持的格式呈现，对比度计算使用实际合成背景。

## B. 状态与可读性

- [x] B3：必要图形、曲线与焦点指示在相邻背景上的对比度 ≥ 3:1。
- [x] B4：高对比主题主文字 ≥ 7:1，次级有效文字 ≥ 4.5:1；禁用与纯装饰内容单独记录。
- [x] B5：设备行、导航项、表格选中行、输入控件逐项检查子控件背景及最终生效样式。
- [x] B6：正常、告警、故障依照既有 severity/状态呈现，文字、图标和颜色含义一致。
- [x] B7：待确认、离线、过期等可用性状态依照现有 Store 事实呈现；颜色调整保持原有状态合同。
- [x] B8：绿/橙/红状态具有文字或图形辅助，灰度观察时仍可辨认状态。
- [x] B9：录制中具备明确活动标记与文字，设备故障仍有独立标识。
- [x] B10：常规页面使用中性色分隔，主要操作、当前选择和真实告警各自可辨。
