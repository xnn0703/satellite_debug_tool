# 卫通终端管理工具 v1.9.9

发布日期：2026-11-13

本版修复 macOS 运维版自动更新在下载和摘要校验完成后无法进入安装事务的问题。

## macOS 更新修复

- 构建身份按真实 PyInstaller bundle 布局从 `Contents/Resources/satellite_debug_tool/build_identity.json` 读取，不再套用 Windows `_internal` 目录。
- macOS 自动更新回归改用真实 bundle 布局，覆盖完整包解析、安装目录身份、文件树、切换、健康确认与回滚。
- 冻结包和发行候选门禁按平台正式路径核验唯一身份，避免测试 fixture 与打包流程共同采用错误路径。
- 身份校验强度、TUF 签名目录、SHA-256、codesign、同盘事务和失败回滚保持不变；本版未通过重试或重复身份绕过错误。

## 一次性迁移说明

- v1.9.2～v1.9.8 的 macOS 运维版携带相同的旧路径错误，旧主程序与旧 updater 都无法在安装前读取自身身份，因此不能仅靠远端新包自举修复。
- 这些 macOS 版本需一次性下载并安装 v1.9.9 完整运维包；安装 v1.9.9 后，后续版本恢复应用内自动更新。
- Windows 运维版不受该 macOS bundle 路径问题影响；user 版仍按既定策略人工交付完整包。

## 发行边界

- macOS arm64 仍为 ad-hoc 签名，未执行 Apple notarization。
- 软件测试、构建、候选回执和归档校验不替代 Windows/macOS 实机安装回滚、真实设备、RF、供电、摇摆台或车辆现场验收。
