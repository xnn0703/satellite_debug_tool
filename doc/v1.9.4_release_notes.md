# 卫通终端管理工具 v1.9.4

发布日期：2026-11-13

本版补齐自动化测试的姿态判定、两阶段批次和核验自动补救闭环，扩展 GNSS 融合诊断，并更新 AFD01B2/C/D 实机三维模型与应用发版链路。

## 自动化测试

- 跟踪工况支持设备姿态相对 MS-6222 参考的三轴误差判定，并独立记录锁定、GNSS 定位和调制解调器上线耗时。
- 台架测试与车辆动中通支持同一批次分阶段执行、挂起恢复、参与设备身份续验和最终统一报告。
- 产品模板支持导入固件 BIN 和参数 CSV；准备阶段可自动升级固件、修正参数并回读确认。
- INCOMPLETE 批次支持重新执行核验；批次完成后按冻结配置下发参与设备目标 IP 并保存证据。

## 诊断与界面

- INS TRACE kind2 增加 schema2 解码，展示 GNSS 历元、处理阶段、速度类型、延迟及融合准入结果。
- 工程页和客户总览增加 GNSS 实时诊断窗口，只读呈现实测位置、速度、航向和融合摘要。
- AFD01B2/C/D 使用各自实机 STEP 网格模型；姿态视图增加自适应水平安装参考面、实体参考轴和输入实时联动。
- 修复批次配置详情、天气选项和浅色主题下姿态参考元素的排版及可见性问题。

## 发布与更新

- 新增 `scripts/release.py` 单入口发版编排，支持只读计划、内容绑定确认、仓库外 journal、断点续跑和发布后复核。
- Windows 继续由 GitHub Actions 构建，macOS 由发布 Mac 构建；ops 继续使用 TUF 自动更新，user 继续交付完整安装包。
- ECS 服务器从两份 user 候选和两个已签名 ops catalog 原子生成四份完整包、`SHA256SUMS.txt` 与 `release.json`。
- 大文件完整 SHA-256 和归档 CRC 在 ECS 本机完成，公网只执行有界 HTTPS Range 复核。

## 发行边界

- 用户版不启用应用自动更新；运维版允许自动更新。
- macOS arm64 仍为 ad-hoc 签名，未执行 Apple notarization。
- 软件测试、构建、候选回执和归档校验不替代 Windows/macOS 实机安装回滚、真实设备、RF、供电、摇摆台或车辆现场验收。
