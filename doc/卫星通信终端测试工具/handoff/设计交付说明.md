> 交给工程师做具体实现。本包含**设计语言规范** + **可运行的 HTML 原型**（作精确参照）。

### 1.2 信号调色板（曲线专用，16 色高区分度）

```
#2DD4BF #38BDF8 #FBBF24 #FB7185 #A78BFA #4ADE80 #FB923C #22D3EE
#F472B6 #A3E635 #818CF8 #FCD34D #2DD4BF #F87171 #60A5FA #C084FC
```
相邻通道色相拉开；同一通道在三主题下保持一致。

### 1.3 字体

- **界面文字**：`IBM Plex Sans`（中文回退 PingFang SC / Microsoft YaHei）
- **数字 / 值 / 表格 / 时间戳**：`IBM Plex Mono`（等宽，`font-variant-numeric: tabular-nums`，避免跳动）

### 1.4 字号

| 用途 | px | 字重 |
|------|----|----|
| KPI 数字 | 26 | 600 |
| 标题 H2 | 16 | 600 |
| 正文 | 13 | 400 |
| 次要 / chip | 11–12 | 500 |
| 微标签（统计行 / 表头） | 10 | 600，字距 .07em，大写 |

### 1.5 间距 / 圆角

- 间距阶梯：`2 / 4 / 6 / 8 / 12 / 16 / 20 / 24 / 32`
- 圆角：`xs 3 · sm 5 · md 7 · lg 10 · pill 999`（工程感，偏小）
- 阴影：仅弹窗 / 浮层用（`0 12px 40px rgba(0,0,0,.6)`）；卡片用边框分隔，不用阴影。

## 2. 图标系统

替换原 `⚙ 🔄 ●` emoji。统一 **1.7px 描边线性图标**，24×24 viewBox，`stroke=currentColor`。
源在 `icons.js`（`P` 对象，键=名，值=内层 SVG path）。已含：satellite / antenna / plug / unplug / link / cpu / wifi / record / play / pause / settings / sliders / refresh / download / upload / import / trash / map / lock / target / compass / location / activity / signal / gauge / flag / clock / 等 60+。

**给 Qt**：把每个导出为独立 `.svg` 文件（本地，离线可用），用 `QIcon`/`QSvgRenderer` 加载，描边色用 `currentColor` 处理为按主题着色（或每主题预生成一套）。

## 3. 组件规范

| 组件 | 规格要点 |
|------|---------|
| **按钮** | 高 28（紧凑）/ 31（舒适）。主按钮 = accent 实底 + accent-ink 文字（Connect 用）；次按钮 = card-2 底 + border-2；危险 = err 软底；幽灵 = 透明。icon 按钮 28×28 方形。 |
| **输入框** | card-2/panel-2 底，border-2，聚焦时 accent 边框 + 3px accent 柔光环。标签前缀小字 text-2。数字右对齐等宽。 |
| **分段控件** | panel-2 容器内 2px 内边距，选中项 card-2 底 + 微阴影；accent 变体选中文字用 accent-2。用于 单图/分组 等互斥切换。 |
| **状态胶囊 chip** | 圆角 pill，左 7px 圆点（按状态着色 + 同色辉光），`KEY 值`（值用等宽加粗）。状态色软底 + 同色边框。 |
| **KPI 卡** | 左 2px accent 竖条（warn/err 时变色）；上微标签（大写字距），下 26px 等宽数字 + 单位，再下 σ/avg 副值。 |
| **通道行** | `[勾选框][色块][名][值]`。**勾选 = 控制曲线显隐**（修原痛点 P0）；勾选框选中 = accent 实底 + 勾。未勾整行 50% 透明。 |
| **事件项** | 左 2px 等级色条 + 等级徽标（INF/OK/WRN/ERR）+ 时间（等宽）+ 消息。右栏标题带未读数字徽标。双击跳到曲线/地图对应时刻。 |
| **状态栏（顶部连接条）** | 左：醒目设备状态卡（图标 + 设备名 + LINK 状态）；中：Type/IP/Port 紧凑输入 + **Connect 主按钮强调**；右：REC/Import/Clear + FPS/CH/FRM/ERR 统计（上移，修原痛点）。 |
| **状态条 strip** | 极简点阵 chip 单行；超出收成 `+N 更多` 可展开（修「换行跳高」痛点）。 |

## 4. 各 Tab 行为

- **实时**：`Connect` → 握手(~1s) → INS 对齐(~6s, ALIGN→DONE) → 流式画曲线（10Hz 模拟，峰值降采样到窗口）。SCAN↔TRACK 自动切换并推事件（LOCK_ACQUIRED / TRACK_LOST）。通道勾选控显隐；单图/分组/归一化/Y自动；REC 计时；通道筛选。右栏 3D 姿态（CSS-3D 立体相控阵，随 roll/pitch/yaw 翻转 + 波束端点）。
- **回放**：`Open .sdb` → 时间轴双手柄选窗 + 播放游标（20×）；曲线随窗口切片；事件标记在时间轴 + **真实地图（Leaflet + CARTO 暗/亮瓦片）上按 GPS 位置打点**，点事件跳时刻，拖游标地图当前位置同步。
- **Log**：`Open .log` → 解析为分列曲线（每列独立 Y），单图/归一化可选。
- **设备**：连接后显设备信息卡 + 可编辑参数表（改值→「已修改」→应用）+ OTA 四步进度（传输/校验/写入/重启）。未连接显空态引导。
- **全局**：主题循环（深/强光/浅）、设置弹窗、检查更新完整流程（检测→更新内容→下载进度→启动升级器）。

## 5. 已修的原 Review 痛点（对照原文档）

| 原痛点 | 本设计处理 |
|--------|-----------|
| P0 通道勾选不控显隐 | 勾选 = `curve.setVisible`，所见即所得 |
| P0 归一化后 Y 轴消失无提示 | 归一化为独立按钮 + toast 说明；保留各曲线真实量纲于 legend |
| P1 工具栏找不到 Connect | Connect 设为 accent 主按钮，连接条分组（状态/输入/动作/统计） |
| P1 事件线被忽略 | 右栏未读数字徽标 + 等级色条 + 双击跳时刻 |
| P1 4 列拖动宽度记忆 bug | 建议固定 3 列 + 最小宽度 +「复位布局」（原型为固定栅格） |
| P2 chip 元素过多 | 简化为「点 + KEY 值」点阵式 |
| P2 三主题 primary 不统一 | 统一为青色 accent，三主题同源 |
| P2 缺图标系统 | 60+ 线性 SVG 图标集 |
| P3 状态栏临时消息一闪而过 | 改为右下 toast（2.6s）+ 持久状态进卡片 |

## 6. 实现建议（Qt 侧）

1. **先落 token**：把 §1 三套颜色 + 字号 + 间距写成 `styles.py` 的 palette dict + `font_px()`，QSS 用 `.format(**palette)` 注入。
2. **图标**：`icons.js` 的 path 批量导出 `.svg`，建 `IconRegistry`，按主题着色。
3. **组件**：按 §3 写 QSS 类（`QPushButton[variant="primary"]` 等）+ 少量自绘（chip 圆点辉光、KPI 竖条、3D 姿态用现有 pyqtgraph.opengl）。
4. **曲线**：沿用 pyqtgraph；颜色取 §1.2 信号色板；勾选控 `setVisible`。
5. **回放地图**：现有 Leaflet + 本地 tile 方案即可，按 §4 在 GPS 位置叠事件 marker。
