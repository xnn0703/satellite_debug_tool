# M19-A9 摇摆台运动指令模型验收标准

## A. 数据模型

- [x] 新建档案、内置型号档案和导出 JSON 均不包含 `max_step_deg`。
- [x] 档案编辑界面不显示“单步角度”字段。
- [x] 合法 v1/v2 档案先通过原版本 SHA-256 校验，再迁移为 v3，且 endpoint、轴符号、标定 ID、绝对范围和周期包络保持一致。
- [x] 被篡改的 v1/v2/v3 档案均拒绝加载。
- [x] v3 保存、重载及 SHA-256 往返一致。

## B. 绝对运动

- [x] 从 `0°` 到 `5°`、三轴组合位姿、回中和复位各只生成一条 A6T。
- [x] A6T 中的完成时间等于用户填写的总完成时间，不再被拆分。
- [x] 超过绝对角度或 Z 范围的目标在发送前拒绝。
- [x] 请求在指令发送后保持 busy 到计划完成时刻。
- [x] 停止操作不发送额外回中指令，并准确记录当前 A6T 已发送的事实。

## C. 正弦轨迹软件验证

- [x] 三轴目标由同一单调时钟生成，相位关系与配置一致。
- [x] 第一条运动指令目标为下一采样时刻，完成时间为一个采样周期，不产生起步空周期。
- [x] 渐入起点和渐出终点均为零姿态，最后一条 A6T 精确结束在轨迹终点。
- [x] 调度使用绝对 deadline，发送耗时不会形成累计漂移。
- [x] 晚到跨越一个完整轨迹点时终止轨迹并报告 timing fault；不存在追赶式连续补发。
- [x] 速度和加速度门禁包含载波与渐入/渐出包络导数。
- [x] 多小时轨迹的预检仍为常数时间，不按样本总数展开。
- [x] `100/50/20 ms` 三档均可记录实际发送周期、最大 jitter、超期和失败；`20 ms` 未通过真机验证前不作为正式默认值。

## D. 回归测试

- [x] 原先稳定复现“`5°` 被拆成三条 A6T”的测试改为证明只发送一条 A6T。
- [x] 删除所有依赖离散步长门禁的旧测试与旧文案。
- [x] 夹具档案、运动平台、控制 worker、夹具页面和生产工作区相关测试通过。
- [x] `python3 scripts/update_translations.py update` 与 `check` 通过。
- [x] `PYTHONPATH=. pytest satellite_debug_tool/tests` 全量 `1426 passed`。

## E. 真机验收

- [ ] 从回中姿态执行 Roll/Pitch/Yaw 小幅单轴运动，确认一条 A6T 能按设定时间连续到位。
- [ ] 从小幅、低频开始执行三轴正弦轨迹，分别比较 `100 ms` 与 `50 ms` 采样周期。
- [ ] MS-6222 记录完整覆盖渐入、稳态、渐出，且无串口缺帧导致的证据空洞。
- [ ] 报告目标/实测曲线、跟踪误差 RMS/最大值、相位滞后、速度边界尖峰、发送 jitter 和 timing fault。
- [ ] 现场急停、软件停止、网络中断和服务程序退出分别验证；软件不把“指令已发送”表述为“平台已到位”。
- [ ] 平滑性阈值由首轮 MS-6222 数据和供应商能力共同冻结；阈值冻结前只记录测量结果，不签署机械平滑性 PASS。
- [ ] 用 MS-6222 设备 GPS 时间计算命令到姿态的固定延迟、幅频响应和相频响应；主机串口回调时间不作为唯一动态时间依据。
- [ ] 在任何反馈外环实施前，另行冻结闭环带宽、修正限幅、过期门限、稳定裕度和异常退出验收；M19-A9 不把观测链路接入运动控制输出。

## F. 一键自动资格测试

- [x] 摇摆台测试页面可选择 MS-6222 串口并显示合法帧、频率和质量状态。
- [x] 自动测试启动前同时获取摇摆台和 MS-6222 租约；独立 MS 测试占用串口时明确拒绝启动。
- [x] 完成安全确认并选择串口后，单击自动测试可自动打开 MS-6222、等待有效姿态帧并建立工程证据会话。
- [x] 一键依次完成中心、Roll/Pitch/Yaw 正负 `3°` 和中心复核，每阶段只有一条 A6T。
- [x] MS 断线、长期无合法姿态、证据写入失败、平台发送失败或用户停止时，停止后续指令并保存 `INCOMPLETE` 证据。
- [x] 自动摘要包含方向映射、符号、响应幅值、交叉耦合、静态噪声、回中偏差、响应延迟、上升时间、稳态误差和数据完整性。
- [x] 未确认坐标标定时只给出建议映射和工程测量，自动结论保持 `INCONCLUSIVE`。
- [x] 测试结束生成自包含诊断 ZIP；ZIP 内包含已完成会话及 SHA-256 manifest。
- [x] 自动流程运行期间，手动移动、轨迹、标定、档案切换和独立 MS 测试入口均不可并发占用硬件。
