# M43 Shell 输入与终端回显验收标准

## A. 根因回归

- [x] UTF-8 `E2` / `80 94` 在旧实现稳定复现失败，新实现正确显示 `—`；同一 RX 解码一次。
- [x] ANSI、UTF-8、CRLF 在整包、全部二分切点及逐字节交付时，正文、光标和颜色结果一致。
- [x] 脱敏真实会话 fixture 保存原始 TX/RX，复现首次中文符号及第二次 `extt_ins_rot` 的编辑链；输入校验拦截导致污染的文字提交。
- [x] 异常 UTF-8 有可见标记和提示；后续正常字节继续解码；原始证据保持原字节。

## B. 终端模型

- [x] BS 按终端语义左移，随后覆盖；中间插入/删除的设备回显与横向光标跨包保持。
- [x] CR、LF、EL、SGR、水平光标操作由单一模型消费；Qt 仅投影模型，用户选择文本不改变设备输出光标。
- [x] 固件日志清行与 OTA 进度覆盖得到正确文本，时间戳每行唯一且不参与设备光标坐标。
- [x] ASCII、中文宽字符和组合字符显示及覆盖有确定单元格行为；异常字节在正文可见。
- [x] 清屏清理解码与屏幕状态；正文/HEX 切换继续处理正文模型；主题切换保留文本、颜色源角色及光标。
- [x] 终端历史与控制序列缓冲有明确容量，长时间接收持续可用。

## C. 输入及相邻入口

- [x] ASCII `_`、数字、空格、普通命令按原字节发送；Shift+- 生成 `_` 时发送 5F，产生 `——` 时整次拒绝并提示英文/ABC。
- [x] 中文破折号、全角字符、不可见非 ASCII 在键盘、粘贴、输入法 commit 使用同一校验；拒绝时发送字节为空。
- [x] 混合粘贴整次拒绝；允许的 CR/LF/TAB 保留既有语义；粘贴 ESC/其他控制字符整次拒绝。
- [x] 方向键、历史、退格、Delete、Home/End、Ctrl 命令与选区 Ctrl+C 保持键值合同。
- [x] TCP/串口与用户/运维两版共用输入策略；YMODEM 二进制及原始文件名保持原样，普通命令预检覆盖全部文字提交入口。
- [x] 提示支持中英文，翻译 update/check 通过。
