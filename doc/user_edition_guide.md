# 卫星通信终端工具 · 用户版

启动 `SatelliteDebugTool.exe`（Windows）或 `SatelliteTerminalToolUser.app`（macOS）。

1. 在设备列表点击添加，填写设备 IPv4 和 UDP 端口（默认 4004），再从总览发起连接。
2. 总览查看设备身份、状态、温度、姿态与波束信息；录制按钮将当前设备数据保存为 SDB。
3. 射频控制页提供当前型号支持的日常控制。请求已发送、设备已接受、回读已应用按实际证据分别显示。
4. 回放页打开现有 SDB 文件查看历史设备数据。
5. 固件升级页选择与当前设备匹配的已认证加密固件包，确认后安装。字节校验和重启后目标版本确认是独立阶段。
6. 侧栏 Shell 打开终端弹窗，支持 TCP（默认 1235）、串口（默认 115200、8N1）与 YMODEM 文件传输。设备接收命令由设备固件决定；传输完成后仍需独立确认重启与版本。关闭弹窗会断开并完成会话证据记录。
7. 顶栏设置用于语言、录制目录和日常连接偏好；检查更新仅提供用户版更新包。

运维版提供工程诊断、安装标定、外接电源、网络测试、摇摆台和试产工具。
