# M45 Shell 终端有界消费与按帧投影验收标准

初值标注"实测冻结"的阈值，实现完成后按 dev_log 度量修订并冻结；其余为合同断言。

## A. 合同回归

- [x] RxRing：容量边界与分段接纳；满载有界等待片段（≤ 20 ms）可被 wake_stop 立即唤醒；push_final 残余移交非阻塞且 drain 先环内后残余；入队/排空/pending 标志同锁协调，无漏唤醒；TCP 与串口单次读取 ≤ 64 KiB；串口积压 > 64 KiB 的 stub 停止回归：分批读取、残余按块移交、transcript 逐字节完整。
- [x] 帧合并坐标：帧内多次淘汰、单帧淘汰超过旧文档行数、空 tokens、纯 SGR 变化、跨包同行覆盖，投影行内容与逐 token feed 的终态逐行一致。
- [x] 终排空顺序：停止时 ring 满且有部分入环数据——已读字节全部消费（transcript 顺序完整、终端呈现末字符）；decoder.finish() 后无残字；dialog 销毁推迟到排空完成。
- [x] 关停顺序：controller 先收尾（含残余移交），文本日志最后关闭；文本日志包含全量消费内容。
- [ ] 应用退出收尾：满环状态下关闭主窗口，closeEvent 泵事件完成末帧投影与日志关闭后才退出；事件循环结束后不依赖 QTimer、不残留未排空数据。
- [x] 代际：连续重连 ≥ 3 次（含洪水中重连），迟到旧 pending/disconnected 不影响新会话；重连前旧 bridge 收尾完成。
- [x] pending 竞争：生产与消费交错于末次 drain 附近不丢通知、不死锁。
- [x] controller 信号修复：自然断链、主动断开、重连三路径 UI 侧均收到 `disconnected`；`ymodem_finished` 在实际传输的完成、取消、失败路径送达，无 YMODEM 事务的断链不要求该信号；私有槽先更新状态后外发。
- [x] undo：正文与 HEX 文档创建即显式 `setUndoRedoEnabled(False)`；持续投影后两文档 `isUndoAvailable()` 恒为 False（HEX 现状由 maximumBlockCount 隐式关闭，回归防退化）。
- [x] 清屏（代际划界）：清屏时已入环与 worker 在途旧字节均不进入新屏幕；UI 立即清呈现，drain 观察到代际推进后重置 decoder 与模型；跨清屏 UTF-8/CSI 分片的续片按无效序列呈现；transcript 保持全量；清屏后新到字节正常呈现。
- [x] 同步入口 feed_rx 与真实路径共用解码/模型/投影实现；洪水中 UI 线程不因满环无界等待。

## B. 持续速率与交互（阈值初值，实测冻结）

- [x] 持续消费速率：满载 5000 行 + 92,160 B/s 注入 ≥ 10 s（注入服务独立线程），预热后按帧累计的 UI 实际消费速率 ≥ 92,160 B/s，注入期间 backlog 随时间有界并记录曲线；注入端记录实际发送进度，TCP 背压导致实际注入速率低于目标即判不达标。
- [x] 突发恢复：输入停止后 5 s 内 backlog 归零（独立指标，不证明持续速率）。
- [x] 正文文档块数 ≤ max_rows（maximumBlockCount 拥有物理淘汰；实测稳态恰为 5000）。
- [x] 帧回调总耗时：稳态目标 ≤ 33 ms；满载退化上限 150 ms。实测满载均值 21.2 ms、最大 34.8 ms（解析 13.7 / 投影 7.5），记入 dev_log。
- [x] 洪水注入下键盘输入到命令入队 P99 实测 23.6 ms（max 24.5）；断开按钮响应实测 45 ms。链路发送时延未单独记录（保留未勾）。
- [x] 512 KiB 日志流全路径实测 1.38 s（宽松退化门槛）。
- [ ] 阈值冻结规则：内部参数（环容量、预算、帧距）实测后可调整；放宽用户可感知验收指标（持续速率、P99、断开响应）须在文档明确说明并重新确认。

## C. 负载矩阵与专项回归

- [x] 突发 64 KB 块；20 B @ 50 Hz 小包高频；ANSI 色彩流；≥ 4 KB 长行；HEX 开启（双文档路径）；文本日志开启。各负载独立成用例，吞吐与块数上限断言。
- [x] 四组专项回归：停止时 ring 满且有部分入环数据；连续重连；帧内多次淘汰；pending 末次 drain 竞争（与 A 节对应用例相互独立）。

## D. 端到端与交付证据
