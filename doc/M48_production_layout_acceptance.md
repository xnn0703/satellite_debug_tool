# M48 布局验收标准

状态：2026-10-30 用户确认方案并授权实施；与 M48 计划对应。

1. **设备数量与身份**：1、2、3、4 台分别只显示对应数量的曲线；单台全宽。唯一参与者即使处于历史 slot 4 仍能显示，控件/controller 不重绑其他 endpoint；未参与设备不占空位。
2. **节点范围**：节点由本批次启用的实际步骤生成，关闭某工况后其节点消失且序号/总数一致。必需步骤、派生分析、未支持/缺判据项目的事实和准入保持正确，界面不通过隐藏失败/未完成项宣称通过。
3. **阶段与时间**：当前测试、阶段、n/N、已用和剩余时间持续可见；计时消费 M47 快照。搜星、观测、收尾、失败、中止、结束与设备卡片一致；单个设备失败不会被显示为重新初始搜星。
4. **夹具指示灯**：READY/有效执行、未就绪、无关分别有绿/红/灰及明确文字。CONFIGURED、CONNECTING、CONNECTED、FAULT 不能误显示已就绪。鼠标或键盘可查看端点和回读/故障原因，颜色不是唯一信息载体。
5. **操作与日志**：事件可展开/折叠且历史完整；固定操作区在最小支持窗口仍可见，中止流程持续响应，报告按钮沿用领域准入。配置详情可查看，冻结后保持不可改。
6. **响应式**：验证 1～4 台、最小支持窗口、常用宽屏及高 DPI；节点数量增多时有可达的横向滚动/换行策略，无文字覆盖、截断关键时间或遮挡操作。三设备不渲染第四张空卡。
7. **生命周期**：隐藏页面停止呈现定时器，执行继续；恢复从 Store 立即补齐阶段、倒计时、节点、夹具和曲线。无第二个计时或业务状态 owner。
8. **主题与语言**：light/dark/dark_hc、中文/英文切换后已有状态完整重绘，大小与布局可读；实现明确 retranslate_ui，维护 TS/QM 并执行 update/check。
9. **根因回归与软件验证**：新回归稳定暴露旧固定四卡、右侧拥挤和无关项目呈现问题；检查布局变化不改设备目标/租约/控制请求。对照计划 review、相关 pytest 和全量检查通过。
10. **现场边界**：效果图和离屏 UI 验收为软件证据；真实上电、摇摆、参考测量、SNR 与正式工况验收独立记录。
