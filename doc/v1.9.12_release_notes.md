# 卫通终端管理工具 v1.9.12

发布日期：2026-11-14

本版修复 v1.9.11 macOS 运维版完成下载和目录替换后，新版试运行进程在健康确认前退出并自动回滚的问题。

## 自动更新修复

- 健康试运行入口统一由安装平台合同解析：Windows 使用
  `SatelliteTerminalManager.exe`，macOS 从 `Info.plist:CFBundleExecutable` 读取
  `Contents/MacOS/SatelliteTerminalManager`。
- 删除健康检查中写死 Windows 可执行文件名的分支；下载、摘要、目录切换、健康回执和失败回滚继续使用原事务合同。
- macOS 自动更新测试使用与正式 PyInstaller app 一致的入口名称，并新增 Windows/macOS 正确入口和错误入口回归。
- 不通过延长超时、重复启动或 LaunchAgent 绕过候选健康确认。

## 验证范围

- 源码全量回归、翻译检查、字节码编译及差异检查通过后才创建发行标签。
- Windows 候选继续由 GitHub Actions 构建；macOS 候选继续由发布 Mac 构建；两平台 ops 进入同一 TUF publication。
- 本版不生成差量包，运维版自动更新下载经过签名目录和 SHA-256 校验的完整安装包。
- user 版不启用应用自动更新，继续通过服务器完整安装包人工交付。

## 发行边界

- macOS arm64 仍为 ad-hoc 签名，未执行 Apple notarization。
- 构建、候选、服务器摘要和软件回归不替代真实 v1.9.11 → v1.9.12 自动重启与健康提交验收；本版发布完成后由现场独立验证。
- 真实设备、RF、供电、摇摆台、车辆和 Windows 现场安装回滚仍是独立验收边界。
