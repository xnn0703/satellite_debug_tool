# M54 验收标准

2026-11-02。与 M54 计划一一对应；实现后填写开发记录，不以软件测试替代现场认可。

| ID | 验收要求 |
| --- | --- |
| A01 | 默认连续 5 秒健康确认搜星；初扫、精扫及确认期间的零值允许重新开始确认；300 秒为搜星上限，包含在工况总时间内。 |
| A02 | 同帧 valid mask、LOCKED、locked=true、有限正 SNR 共同决定健康；失锁但正 SNR 形成中断；NaN/Infinity/无效字段形成质量问题。 |
| A03 | 事件≤2秒、次数≤每30分钟5次的比例配额、累计≤正式观察时长0.5%，边界相等允许、超过失败。 |
| A04 | 连续健康3秒确认恢复，事件结束回填到恢复起点；不足3秒又异常合并同一事件，正确计入中间短恢复。 |
| A05 | 到窗口结束尚未确认恢复：已超限FAIL保留，其余INCOMPLETE；稳定恢复且其他条件满足才PASS。 |
| A06 | 显式无效数据、开始/结束缺失和超过2秒采样间隔形成质量问题；缺口不视为正常、不中断固定计时、不跨缺口确认稳定。 |
| A07 | 锁定后摇摆在运动前连续5秒确认，ARMED准备中失锁重新确认；首个移动反馈后立即评价，包含渐入期；前置等待300秒超时保存判定且不伪造硬件启动。 |
| A08 | 每个测试项使用自身duration_s，配置、冻结、倒计时和报告一致；自动轨迹由观察结束停止，准备延迟不缩短观察；共享供电恢复等待本次OFF/ON、新身份/Service、新采集nonce应答和时间相容数据及新鲜参考，同scope可开窗且开窗重置观察锚，准备超时形成INCOMPLETE；旧时长迁移保留数值和来源，历史结果保持。 |
| A09 | 两台及四台设备独立统计；单台FAIL不终止其他设备和后续项目；共享夹具故障/人工中止保留既有收尾。 |
| A10 | 每项结果包含规则版本、搜星时长、中断数/最长/累计/比例、数据质量、失败原因；界面与报告同源。 |
| A11 | 未选项目不强制加入；空参数/optional固件不标为实际比较PASS；显式启用但未实现的导航项目清楚呈现INCOMPLETE。 |
| A12 | 明确性能FAIL与证据不足同时保留；无SDB/无分析帧/质量缺口阻止审核PASS；审核原因与原结论独立留存。 |
| A13 | B2 24V预置为8A并提高revision；12V仍9A，C/D仍原参数；导入导出及自定义副本保持独立身份。 |
| A14 | B2数量1/2/3/4分别计算8/16/24/32A及192/384/576/768W；超过电源或支路档案阻止启动，工位额定值保持真实。 |
| A15 | 原始静态瞬降录制按新规则复算，明确与旧结果的差异；不覆写原批次、旧报告或原始SDB。 |
| A16 | 专项、相邻及全量pytest、翻译update/check、diff检查；GUI展示实际规则/事件统计，软件和硬件验证分列。 |

现场待验收：确认8A支路接线能力，观察设备实际电流；受控人员遮挡试验记录持续时间、自动恢复、SNR/锁定状态；据结果评估试行门限。
