# Satellite Debug Tool — UI 设计审查文档

> 目的：交给设计师做 UI/UX review。本文档自包含，读者无需项目背景。
> 当前版本：v1.0.0（M1–M11 累计交付）
> 关联截图：建议附 `doc/screenshots/UI_*.png`（需现拍）

---

## 0. TL;DR — 这是个什么应用

**Satellite Debug Tool** 是一款**桌面端调试工具**，给"相控阵卫星通信终端"
设备做实时调试 / 录像回放 / 日志分析 / 固件升级。

| 维度 | 取值 |
|------|------|
| 平台 | macOS（Apple Silicon）+ Windows 10/11 |
| 用户 | **嵌入式开发工程师** + **现场调试工程师**（少量产品经理偶尔看） |
| 使用场景 | 实验室桌面（80%）/ 车载强光屏 500cd/m²（15%）/ 户外日光（5%） |
| 典型 session 时长 | 30 min – 8 h（联调 / 长跑测试） |
| 显示尺寸 | 笔记本 13–16"（主流）/ 外接 4K 偶尔 |
| 用户操作熟练度 | 高（嵌入式工程师，命令行重度用户，能接受复杂界面） |
| 视觉风格预期 | 工程师向、信息密度高、深色为主、不追求消费级"美" |

## 1. 功能全景

### 1.1 数据流核心

```
设备（卫星通信终端）
    ↓  自定 v2 二进制协议
    ↓  Serial 或 UDP @ 4004
上位机 FrameReceiverV2 解析
    ↓
分流：
  - DataReport   → 时序通道（roll/pitch/yaw/snr/...）→ Chart
  - StateReport  → 离散状态（LINK/LOCK/GPS_FIX/...）→ Status / Dashboard
  - EventReport  → 事件流（TRACK_LOST/MODE_CHG/...）→ Event Timeline
  - MetaInfo     → 设备元（hw_type/fw_ver/sn）→ Profile
```

### 1.2 4 大 Tab 功能矩阵

| Tab | 主要功能 | 用户高频动作 |
|-----|---------|------------|
| **实时（Live）** | 连接设备、实时画曲线、看状态灯、3D 姿态、录制 .sdb | 连接 → 看曲线 → 标记问题点 |
| **回放（Playback）** | 离线打开 .sdb 文件、时间轴拖动、地图轨迹 | 打开文件 → 拖时间轴 → 找问题 |
| **Log** | 解析 WindTerm 串口 log 转曲线 | 选 log → 看曲线 |
| **设备（Device）** | 参数表（IP / 模式 / ...）读写、固件 OTA 升级 | 改参数 → 升级 |

### 1.3 跨 Tab 公共能力

- ⚙ **设置** 弹窗：默认路径配置、图表分组管理、自动更新设置
- 🔄 **检查更新**：从 Gitee 拉新版自动下载升级
- **主题切换**：深色 / 深色高对比 / 浅色三档
- **离线地图**：Leaflet + 本地 tile，回放/Log 检测到 GPS 通道自动启用

### 3.2 关键组件细节

#### 3.2.1 GroupedChartWidget — 核心曲线区

**工具栏（顶部一行 24px 高）**：
- `[单图]` / `[分组]` toggle 按钮（互斥）— 决定所有曲线叠一张图还是按 group_id 分子图
- `[全部隐藏]` toggle — 一键所有 curve.setVisible(False)；再点恢复
- `[归一化]` toggle — 每条曲线按自身可视窗口 min-max 缩放到 [0, 1]，legend 后缀显示真实 [-180..180] 之类
- `[Y 自动]` 触发按钮 — 复位所有子图 Y 到 display_min/max；用户手动 Y 缩放过的子图 Y 轴文字变橙色提示

**子图区域（QScrollArea，超出可滚动）**：
- 每个子图：标题（如"姿态 / 指向 / 信号 / PID / 位置"）+ Y 轴刻度 + X 轴时间（秒）
- 多曲线：每条曲线一种颜色（高区分度 20 色调色板）+ 右上 legend
- X 轴**全局联动**（拖动 X 全部跟）；Y 轴**各子图独立**（鼠标在某子图 wheel 只缩放它的 Y）
- pyqtgraph 默认右键菜单（缩放 / 导出图片 / autoRange）保留

**性能优化**（用户可能看不到但影响体验）：
- Live 模式：setData 前峰值降采样到 ~3000 点，避免 30k 点全量阻塞 UI
- Playback 模式：靠 pyqtgraph auto-downsample 保 zoom 细节

**已知小问题**：
- 工具栏 4 个 toggle 按钮文字稍多（"归一化"3 字，"Y 自动"3 字）排在一行可能拥挤
- 分组模式下子图标题字号偏小

#### 3.2.3 StatusStripWidget — 状态条（M10 改 FlowLayout）

```
[● LINK OK] [● REC] [● BEAT] | [● TRACE_MODE: SCAN_GLOBAL] [● LOCK_FLAG] [● GPS_FIX: 3D] [● INS_STATUS: ALIGN_DONE] [● PLL_LOCKED] [● MODEM_CONNECTED]
```

**Chip 视觉**：
- 圆角胶囊（border-radius: 10px）
- 左侧 12px 圆点（绿/黄/红/灰按状态色）
- 文字 ~11px

**自适应**：
- 窗口宽 → chip 一行排满
- 窗口窄 → 自动换行，状态条高度增加
- 极窄屏（< 单 chip 宽度）→ 每行 1 个，仍不出滚动条

**已知问题**：
- 极窄屏时状态条高度可能撑得很大（5 行以上），抢曲线区空间
- chip 分隔符 `|` 在换行后位置突兀（M10 后没特别处理）

| 痛点 | 当前现状 | 设计师值得 review |

## 8. 视觉系统

### 8.1 主题色板

3 个主题，由用户在全局工具栏切换：

| 角色 | dark（默认） | dark_hc（高对比） | light |
|------|--------------|-------------------|-------|
| bg 主背景 | `#1E1E1E` | `#000000` | `#FFFFFF` |
| panel 面板 | `#252526` | `#0A0A0A` | `#F5F5F5` |
| card 卡片 | `#252526` | `#141414` | `#FAFAFA` |
| border 边框 | `#3C3C3C` | `#404040` | `#E0E0E0` |
| text 主文字 | `#CCCCCC` | `#F5F5F5` | `#333333` |
| text_muted 次文字 | `#888888` | `#BBBBBB` | `#666666` |
| success 成功（绿） | `#4EC9B0` | `#00FF88` | `#007A5E` |
| warning 警告（黄） | `#DCDCAA` | `#FFD700` | `#B88600` |
| error 错误（红） | `#F14C4C` | `#FF4040` | `#C62828` |
| primary 主按钮 | `#0E639C` | `#1DA1F2` | `#0E639C` |

**已知问题**：
- dark 主题对比度对一些老年用户不够（已有 dark_hc 兜底）
- light 主题没经过设计师打磨，按钮 hover 态偏弱
- 三个主题的 primary 蓝色饱和度差别大（设计师可统一）

### 8.2 字号

固化使用 "small" 档：

| 用途 | px |
|------|-----|
| 主文字 | 12 |
| 次要文字 / chip label | 11 |
| KPI 数字 | 18+ |
| 表格内容 | 12 |
| 工具栏按钮 | 11 |

**注**：M6 曾做过 4 档字号切换（small/medium/large/xlarge），M7 砍掉了 UI 入口，
代码保留向后兼容 API。如果设计师建议加回多档字号，技术上半天能恢复。

### 8.3 间距系统

无统一 token，typically：
- 紧凑组件 spacing: 4px
- 一般组件 spacing: 6-8px
- 卡片内 padding: 8-12px
- 工具栏内 padding: 2px

**已知问题**：无 token 系统，设计师如要全局调整需逐处改 style sheet。

### 8.4 等宽字体

KPI 数字、值标签、表格数字字段强制等宽：
- mac: Menlo / SF Mono
- win: Consolas / Cascadia Code
- 兜底: monospace family

## 9. 交互约定

| 操作 | 含义 |
|------|------|
| 左键单击按钮 | 触发 |
| 左键拖动 splitter | 调整面板宽度 / 高度 |
| 左键双击 chart 空白 | pyqtgraph 默认右键菜单的 autoRange |
| 右键 chart | pyqtgraph 内置菜单（导出图片、autoRange、view all） |
| 滚轮 chart 内 | 同时缩放 X + Y（pyqtgraph 默认） |
| 左键拖动 chart 内 | pan |
| 双击 EventTimeline 项 | chart 跳到该事件时刻 |
| ESC | 关闭弹窗 |
| 全局快捷键 | 无（目前都靠工具栏按钮） |

## 10. 已知 UX 痛点 — 设计师重点关注

按优先级排：

### P0 — 影响用户决策正确性

1. **ChannelPanel 多通道密度**：checkbox 已控制曲线显隐；设计师重点看 20+ 通道时滚动、搜索、全选/清空的效率。
2. **GroupedChart「归一化」打开后 Y 轴刻度消失**，新用户不知道发生了什么。可能需要：开关旁有小图标提示 + 第一次开有 tooltip。

### P1 — 影响效率

3. **ConnectionToolbar 按钮密度高**：10+ 按钮 + 文字标签，初学者找不到 [Connect]。建议主按钮加 primary 强调 / 加图标。
4. **Live Tab 4 列 splitter**：拖动后宽度记忆有 bug，重启可能不复原；建议加 [复位布局] 按钮。
5. **EventTimeline 在右下角易被忽略**：事件是诊断关键信息，应有未读高亮 / 数字徽章。

### P2 — 视觉打磨

6. **chip 圆点 + 文字 + 左侧色条 + border** 视觉元素多，可简化（参考 GitHub status indicator）。
7. **3 个主题 primary 蓝色不统一**，设计师可拉一个色板覆盖。
8. **light 主题** 全套未打磨，按钮 hover 弱、卡片阴影缺失。
9. **icon 几乎没有**：除了 `⚙ 🔄 ●` 几个 emoji，没有正经的图标系统。
10. **dark_hc** 当前只是把对比度拉到底，没专门的"户外强光"设计语言。

### P3 — 长跑可发现的小问题

11. 状态栏临时消息（"已请求采样率 100Hz"）只显示 2 秒就消失，用户来不及看。
12. PyQtGraph 默认右键菜单是英文 + 内容繁多，可能让中文用户困惑。
13. 拖 splitter 没有 hover hint 表明"这里可以拖"。

## 11. 约束（设计师须知）

| 维度 | 约束 |
|------|------|
| **不能用 web 技术** | 纯 PySide6 (Qt 6) + QSS 样式，不能用 React / Tailwind 之类 |
| **不能引入大型设计组件库** | 不接 Material Design / Ant Design（社区 Qt 移植版质量参差） |
| **必须支持 macOS + Windows** | 同一份 QSS，跨平台渲染差异需手动处理（按钮高度、字体回退） |
| **必须支持深色 + 浅色** | 任何新组件必须能跑 3 个主题 |
| **不能依赖网络** | 离线场景常见（外场），所有资源（图标 / 字体）必须本地化 |
| **图标 SVG 优先** | Qt 支持 SVG，避免 png 缩放糊 |
| **不能改变协议层 UI** | StatusStrip / Dashboard 内容由设备 profile 驱动，不能硬编码 |

## 12. 给设计师的需求 / 期望

按重要性排：

1. **建立设计语言**：颜色 / 字号 / 间距 / 圆角 / 阴影 / icon 一套 design token
2. **图标系统**：替换 emoji（⚙ 🔄 ●），用一致风格的 SVG（推荐 Phosphor / Tabler / Lucide 风格）
3. **按钮 / 输入框 / 卡片 3 类基础组件视觉规范**
4. **状态色（成功 / 警告 / 错误）跨主题统一感觉**
5. **复杂组件 review**：ChannelPanel / StatusStrip / Dashboard / EventTimeline 这 4 个会高频出现的
6. **首次使用引导（可选）**：onboarding tooltip？
7. **dark_hc 主题**：户外强光屏专用设计语言（不是简单加对比度）
