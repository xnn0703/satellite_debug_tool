# M19-A.15 夹具姿态同步录制与回放验收标准

## A. 录制模型

- [x] `FixtureRuntime` 发布类型化平台目标、MS 相对姿态和绝对航向样本。
- [x] UI 不直接寻找或写入设备 recorder。
- [x] 只有活动 SDB v3 recorder 接收夹具样本。
- [x] 平台目标明确标记为目标，不命名为平台实测姿态。
- [x] MS 相对姿态包含标定 ID、档案 SHA、质量和原始时间。
- [x] 无效参考记录无效状态和原因，不写伪造有效值。
- [x] 多设备录制获得相同 sample ID，但各自 SDB 归属保持独立。
- [x] 队列满或写入失败产生 recorder 缺口计数和用户可见错误。

## B. 时间对齐

- [x] 使用 SDB 内设备接收主机时间与展开 uptime 生成对齐锚点。
- [x] 只在同一设备启动代际和有效锚点区间内插值。
- [x] 不跨重启、长断线或异常时钟比例区间连接数据。
- [x] 未对齐样本不进入同轴曲线和姿态判定。
- [x] 回放显示已对齐、未对齐、无效和最大锚点跨度统计。
- [x] 文案和开发记录明确为主机时间相关，不声明硬件同步。

## C. 回放显示

- [x] Customer Playback 姿态区域同时显示设备、平台目标和 MS 参考三组 R/P/Y。
- [x] Engineering Playback 姿态组支持相同夹具外部 series。
- [x] 轴颜色与来源线型稳定，图例能直接识别来源。
- [x] MS 绝对航向不替代相对 Yaw 曲线。
- [x] 无标定时不把 MS 原始坐标画成 FRD 相对姿态。
- [x] MS 断流和无效参考以 NaN 断开并显示缺口事件；设备重启和长断线不跨区间对齐。
- [x] 无夹具记录的 SDB v2/v3 文件保持原有回放结果。

## D. 自动化验证

- [x] metadata schema、有限数和来源枚举有单元测试。
- [x] recorder 活动/非活动、限频、队列失败和多设备归属有测试。
- [x] 正常插值、重启代际、长断线、边界外样本和异常时钟比例有测试。
- [x] Customer/Engineering 回放通道分组、线型和缺口事件有 UI 测试。
- [x] 全量测试和翻译检查通过（1447 passed；1363 条翻译通过）。

## E. 真机验收

- [ ] 启动设备录制并运行单轴摇摆，SDB 同时包含设备、平台目标和 MS 相对姿态。
- [ ] 运行三轴组合摇摆，回放三组姿态位于同一区域且方向一致。
- [ ] 中途断开 MS-6222，回放曲线正确断开并报告缺口。
- [ ] 中途重启 DUT，不跨启动代际连接夹具曲线。
- [ ] 两台 DUT 同时录制时，各自 SDB 可独立回放相同共享夹具动作。
