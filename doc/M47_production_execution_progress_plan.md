# M47 批次自动执行与进度呈现计划

状态：用户已确认范围；2026-10-30 按用户补充判据实施，源码验证中。

## 问题与目标

当前启动入口完成电源准备、参与者冻结和批次记录启动；ProductionRunCoordinator 已有 attempt 状态机，但页面启动链路尚未实例化并接入硬件执行。批次运行状态因此能够与全部测试待执行同时存在。

接通真实测试执行链路，并显示当前测试、阶段、步骤序号、已用时间、有效观察时间、剩余观察时间及等待原因。批次采集时长、步骤经过时间与有效观察时间分别表达各自事实。

## 范围

1. 复用 ProductionRunCoordinator 作为步骤推进的唯一 owner；执行服务位于 core/production，UI 只发意图和呈现快照。清除被替代的启动、进度与判定路径。
2. 首轮自动台架流程包含固件核验、参数核验、静置对星、锁定后摇摆、摇摆中上电；按冻结配方选择执行项。导航汇总消费对应工况证据，车辆工况保留明确的人工门禁及支持边界，全部启用项均有可解释状态。
3. 准备分为工位配置/租约检查、电源准备、等待设备启动与身份准入、冻结参与者、逐项执行。消除设备在线作为自动上电前提的循环依赖；在冻结前核对目标数量及产品身份。就绪状态继续消费真实平台反馈与 MS 有效帧。
4. 每项测试具有准备、等待前置条件、执行/收敛、有效观察、分析、完成或失败阶段。固件、参数核验使用配方要求与本次会话回读；平台运动、电源切换消费所属 owner 的回执与回读。
5. 计时使用可注入单调时钟。工况总时长直接来自配方（例如 1800 秒）；初始搜星计入总时长。按 2026-10-30 用户补充，设备有效快照同时确认 `tracking_phase=LOCKED`、`locked=True` 且 `SNR>0` 后初次搜星才完成；初扫和精扫中的短暂正值/归零均属于初始搜星，完成后窗口内每个样本均要求 SNR > 0；任一零值、负值永久记录为该设备失败。锁定与阶段字段用于确认初始搜星结束，SNR 判据仍为大于 0，不增加额外驻留秒数。原有短配方工程属性元数据保持原合同，本轮工况计时和 SNR 判定均采用配方时间。
6. 剩余时间 = max(配方工况时长 - 硬件启动确认后的单调经过时间, 0)。缺口与失联保留证据完整性事实，固定窗口持续计时；有效正值证据时长独立记录。参考失效/平台故障结束当前共享动作并标记未完成。倒计时到零先受控停止并确认回中，再根据逐设备全部样本判定，始终区分 FAIL 与 INCOMPLETE。
7. 页面增加持续可见的当前执行摘要，工作流标识当前行，每台参与设备显示自身测试/阶段/结果。隐藏页面保持后台执行，恢复页面即时呈现 Store 快照。
8. 中止、共享夹具失败、设备代际变化与退出统一完成受控停止、电源关闭验证、attempt 状态和证据收尾。记录步骤时间锚点、有效窗口、硬件动作与逐设备结果供报告复核。

## 实施顺序

- 核查现有配方、分析器、夹具公开接口及测试，确定各测试的准入、收敛、有效窗口和分析合同；缺失合同作为明确阻塞项记录。
- 接通领域执行服务、启动准备与状态快照，补充旧实现复现回归。
- 实现进度与倒计时呈现并更新翻译。
- 对照验收逐项 review、运行相关及全量 pytest；维护同编号开发记录。默认源码交付，打包与提交由用户另行要求。

## 交付边界

## 手动中止补充（2026-10-30 用户要求）

复现并修复按钮点击后无反馈：中止状态由领域 owner 持有，点击立即取消步骤推进并显示“正在中止”，运动线程退出和夹具证据收尾移到后台；等待电源关闭回读及线程退出后才提交 ABORTED。刷新和重复点击保持同一中止请求。关闭失败显示原因并保留资源句柄。准备、等待设备及正式执行入口共用中止路径，补充真实按钮点击、慢速停止和回执顺序的回归。

## 未上电创建批次补充（2026-10-30 用户确认）

创建批次允许缓存设备处于离线、身份授权已过期状态；批次建立录制意图，录制 owner 在本次有效身份授权后取得。正式参与者冻结继续严格要求身份及录制已就绪。复现“已发现过设备→断电离线→创建批次”并覆盖重新上电、首个身份帧恰好录制一次以及真实 I/O 失败仍明确阻止准入。

## 自动工位控制澄清（2026-10-30 用户要求）

正式批次无需先进入电源、摇摆台或 MS 调试页人工连接。开始时按冻结配置设定电源电压及总限流并验证开启；需要台架工况时由同一执行 owner 自动连接配置中的摇摆台及 MS，确认平台反馈/回中和参考有效帧后开始工况。静置、摇摆、摇摆中上电和停止均由执行链路发起。已有人工调试会话占用资源时明确报告 owner 冲突，不创建第二条物理连接。验收增加“工位夹具初始为 CONFIGURED 也可启动准备”及“自动连接参考与平台，回读就绪后开始观察”。
