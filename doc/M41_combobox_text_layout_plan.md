# M41 时间范围下拉框文字布局修复计划

用户反馈回放/日志的“范围”下拉框文字错位。原生 macOS Qt 已复现右侧文字裁切；本次按该反馈完成局部呈现修复。

## 根因与范围

- 时间范围下拉框固定 110 像素宽，无法覆盖中英文长选项。
- 全局样式将 QComboBox 与数值输入框一起设置为等宽字体，弹出视图使用另一套字体。
- macOS 默认菜单委托在 QSS 列表样式下保留菜单选中标记布局，实际文本几何与列尺寸测量不同。

## 计划

1. 明确下拉框使用 UI 字体、数值输入使用等宽字体；框体和弹出列表统一字体角色。
2. 时间范围控件使用 Qt 标准列表委托，按选项内容计算宽度，替换原固定宽度。
   原生页面复核发现回放文件信息与范围同排还会压缩英文内容；回放与日志将文件信息和范围分为两行，消除父布局的同源挤压。
3. 检查中英文切换、三主题、回放与日志共用入口；保持时间范围值与信号合同。
4. 用旧实现复现几何裁切并加入回归，再验证新实现；维护[验收标准](M41_combobox_text_layout_acceptance.md)与[开发记录](M41_combobox_text_layout_dev_log.md)。
