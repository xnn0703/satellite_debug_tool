# 卫通终端管理工具 v1.9.14

发布日期：2026-11-24

本版包含串口 Shell 读取路径修正，解决经调试器虚拟串口连接时长输出截断、随后
串口停止响应的问题。

## 串口 Shell 读取路径

- `SerialShellLink.recv()` 只在超时取值变化时给 pyserial `timeout` 赋值。旧实现
  每次读取都赋值，而 pyserial 3.5 的 `timeout` setter 每次赋值重走端口重配置；
  USB CDC 虚拟串口上该调用实测中位 1030 µs（`in_waiting` 约 1 µs），数据流入
  期间每读一次插入这段等待。
- 修复前的现象：经 RV CMSIS-DAP 探针的虚拟串口连接目标板 shell（921600），
  `app` 的 1303 字节输出在 64–136 字节处截断并伴随非 UTF-8 字节，此后探针
  虚拟串口两个方向停止转发；目标板 TCP Shell 与固件自检（`hd diag`、
  `hd uarterr`）保持正常。
- 修复后同设备实测：`app` 连续三次每次 1303 字节完整并以提示符结尾，`help`、
  `hd ls`、`para ls`、`hd diag` 完整；串口 YMODEM 传输 784392 字节完成。
- 串口打开为 8N1、无流控，DTR 与 RTS 不置位；`send()` 只提交字节，不等待线上
  发完。两项与参照终端 COMTool 一致，实测不是截断的触发条件。
- 回归：`test_tcp_shell_transport.py::TestSerialShellLink` 覆盖开口线状态、发送
  不等待 drain、读取路径不重设超时；旧实现稳定复现失败，新实现通过。

## 验证范围

- 源码全量回归、翻译检查、字节码编译及差异检查通过后才创建发行标签。
- Windows 候选继续由 GitHub Actions 构建；macOS 候选继续由发布 Mac 构建；
  两平台 ops 进入同一 TUF publication。
- 本版不生成差量包，运维版自动更新下载经过签名目录和 SHA-256 校验的完整
  安装包。
- user 版不启用应用自动更新，继续通过服务器完整安装包人工交付。

## 发行边界

- macOS arm64 仍为 ad-hoc 签名，未执行 Apple notarization。
- 串口 Shell 的真机验证在 macOS 上经 RV CMSIS-DAP 探针完成；Windows 实机串口
  Shell 与其它串口适配器由现场独立验收。
- 探针在端口关闭期间缓存的目标板输出会在连接时先显示；设备启动期间缓存的
  内容为乱码，本版原样呈现。
- 构建、候选、服务器摘要和软件回归不替代真实自动更新安装与回滚的现场验收。
- 真实终端、RF、供电、摇摆台、车辆测试仍是独立验收边界。
