# M59 摇摆轨迹编译与缓停回正验收标准

## A. 轨迹编译

- [x] 有限轨迹在首条 UDP 指令前完成全部姿态、六缸目标和 `0xC0` 帧编译。
- [x] 运行热路径不调用逆运动学或帧编码；回归测试注入运行期逆解失败仍不影响已编译轨迹发送。
- [x] 编译结果绑定轨迹、平台配置和预检摘要；任一事实变化后旧结果明确失效。
- [x] 任一点不可达时整条编译失败且发送数为 0，不进行逐缸钳位或自动缩角。
- [x] 30 min / 50 ms 的 36,400 点编译时间和内存形成可审计基准，不阻塞已运行的控制时间线。
- [x] 无限工况只保留有限重复周期或有界前瞻块，不随运行时间增长内存。

## B. 缓停并回正

- [x] 轨迹运行时“缓停并回正”按钮可用，无需结束工程会话或重新取得控制权。
- [x] 点击后状态依次为 `FADING → CENTERING → CENTER_CONFIRMED`；重复点击不产生第二条停止路径或重复中心命令。
- [x] 渐出从最后已发送点的实际相位继续；第一渐出点相对原轨迹没有一个采样周期以上的姿态跳变。
- [x] 渐出时长使用界面已冻结值，幅值包络单调下降，采样周期保持50 ms。
- [x] 渐出结束只发送一次精确中心目标；新鲜反馈证明运动停止且位于目标保护范围后才显示成功。
- [x] 发送失败、反馈失效、伺服错误或中心保护范围不满足时显示 `CENTER_FAILED`，不得显示已回正。
- [x] 应用退出、会话结束和主动缓停共用同一停止 owner；旧“仅设置 stop event 并截断”业务路径被删除。
