# M19-A.2 夹具调试台验收标准

## A. 档案与安全

- [x] 档案具有 schema、revision、稳定 SHA-256，加载后能复现平台 endpoint、位姿、轴符号、calibration ID 和全部硬上限。
- [x] endpoint 非法、revision 冲突、角度/频率/速度/加速度/单步上限非法时明确拒绝。
- [x] 任一周期运动硬上限缺失时禁止周期轨迹；UI 不能输入超过档案上限的值。
- [x] 未完成四项现场确认时不能发送运动命令；关闭夹具页后确认状态被清除。
- [x] 正式批次和夹具调试不能同时持有运动平台控制权。

## B. 平台控制

- [x] 单步只修改目标轴，另外两轴保持最近一次成功发送的逻辑目标。
- [x] 大步移动按 `max_step_deg` 拆分，总完成时间按比例分配，且不会突发连续下发。
- [x] 周期轨迹支持三轴 enable、幅值、频率、相位、渐入、稳定、渐出和采样周期。
- [x] 角度、峰值速度、峰值加速度或离散步长越界时在发送前拒绝。
- [x] 停止只取消后续命令，不隐式回中；回中独立；Z=0 复位必须二次确认。
- [x] UDP 成功仅显示“指令已发送”，不显示“平台在线”或“已到位”。

## C. MS-6222

- [x] 独立 worker 以 `460800 8N1` 被动采集，不复用 Debug worker。
- [x] INSPVAXB、GNSS、RAWIMUSB、GNSS v1/v2 均按固件结构正确解析。
- [x] CRC32 golden vector 与固件算法一致；所有分片位置、粘包、噪声、错误长度和坏 CRC 后均能恢复。
- [x] 无效帧不更新 latest，但原始记录和错误统计完整。
- [x] 实时界面明确显示串口状态、三类报文率、CRC/有效率、原始姿态和质量状态。

## D. 标定、比较与指标

- [x] 引导流程覆盖回中、三轴 `+3°/-3°` 和再次回中，输出轴映射、符号、零偏、响应、耦合、噪声和覆盖率。
- [x] 标定结果需人工确认后写入 calibration 文件，并具有唯一 ID 与 SHA-256。
- [x] 坐标或时间门禁不满足时不展示正式误差指标。
- [x] 比较先应用标定变换，姿态误差使用四元数，Yaw 跨 `±180°` 连续，数据缺口不跨越插值。
- [x] 静态和动态合成数据能得到稳定时间、超调、漂移、幅值比、频率误差、估计相位、RMS/P95/最大残差和非目标轴耦合。
- [x] 无 PPS 时动态相位和时延明确标记为工程估计。

## E. 会话与 UI

- [x] 夹具调试无需创建批次或连接 DUT。
- [x] 工程会话至少保存 manifest、档案快照、平台命令、MS 原始帧、解析数据、对比数据、事件和 summary。
- [x] 异常中止后会话保留 `incomplete` 状态和已有证据；正常结束后保存所有文件 SHA-256。
- [x] 操作者结论支持通过/不通过/无法判定和备注，但固定标记 `ENGINEERING_ONLY`，不得设置 `ReferenceStatus.qualified=True`。
- [x] 长轨迹和串口采集期间 UI 保持响应；关闭运行中的页面需确认并停止后续动作。
- [x] 中英文运行时切换完整；1024x600 和 1280x800 下主要控件无重叠或不可达。

## F. 自动与硬件验证

- [x] 翻译目录检查通过，无 unfinished、空翻译或占位符不一致。
- [x] `PYTHONPATH=. pytest satellite_debug_tool/tests -q` 全绿，除既有四个弃用提示外不新增 warning。
- [ ] 真机依次完成：无 MS 指令测试、三轴引导标定、`±1°/±5°/±15°` 单步、目标组合轨迹、网络/串口中断恢复和 60 min 记录。
