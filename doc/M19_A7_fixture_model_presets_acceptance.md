# M19-A.7 摇摆台型号模板与自动档案验收标准

## A. 型号与档案

- [x] 内置“南京灵境六自由度平台（200 mm）”型号模板，A6/A6T 服务 endpoint 固定为 `192.168.15.101:9800`，不把 `DriverEx=192.168.15.201` 当成 UDP 服务。
- [x] 模板生成的三轴角度、步长、运行包线、A6 几何和最短指令时间与计划一致。
- [x] 新档案保存 `model_id`、展开参数、revision 和稳定 SHA-256。
- [x] v1 档案必须先通过原 SHA-256 校验，再迁移为 custom v2 档案。
- [x] 已生成的 `.201:9800` 当前型号档案自动升级为下一 revision，保留轴符号和 calibration ID，旧 SHA 不再冒充当前标定。

## B. 界面

- [x] 摇摆台测试页直接选择型号，不显示“新建档案”和“重新加载档案”。
- [x] 首次选择内置型号时自动生成内部档案，后续直接加载同一档案及其修订记录。
- [x] 型号参数只读；操作者只配置三轴符号。
- [x] “安装配置”中的内部档案 ID 只读，避免产生同型号的重复档案。
- [x] 引导标定成功后仍生成真实 calibration ID并修订档案，不受型号模板影响。
