# M60 摇摆台独立发送时间线验收标准

## A. 软件

- [x] 真实UDP socket使用独立spawn进程；父进程不执行轨迹帧 `sendto`。
- [x] 父进程仍独占反馈、状态、证据和动作完成事实；子进程只拥有发送时间线。
- [x] 父进程每点故意延迟80 ms处理时，10个50 ms loopback帧全部发送且最大间隔小于100 ms。
- [x] 跨进程缓停按当前实际索引生成渐出段，并取得 `FADING → CENTERING → CENTER_CONFIRMED`。
- [x] worker关闭先停止发送进程，再关闭控制器；无并行旧发送路径。
- [x] ops/user入口具备冻结程序multiprocessing启动支持。
- [x] 完整槽位迟到会保存时序故障、发送当前点并从真实发送时刻重建50 ms周期；轨迹不跳点、不终止、不追赶突发。
- [x] 独立时间线回归注入超过两个周期的晚唤醒，三帧仍按序发送并正常结束。
- [x] 影响面定向回归通过。
- [x] 全量分段回归通过。

## B. 真实台架

- [ ] 10°三轴、50 ms、MS-6222和曲线可见条件下连续运行不少于10 min。
- [ ] pcap控制指令无持续完整槽位丢失，P95/P99和最大间隔满足冻结现场门槛；偶发迟到不导致轨迹退出。
- [ ] 控制器反馈连续、六轴伺服错误为0。
- [ ] MS-6222与人工观察确认无明显卡顿、震动异响。
- [ ] 至少三个不同相位的缓停回正均取得反馈闭环结果。
