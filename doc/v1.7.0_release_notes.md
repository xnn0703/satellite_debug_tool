# v1.7.0 Windows 发布说明

## 主要更新

- TCP Shell 终端新增"自动保存会话日志"开关：开启即创建 `<IP>_YYYYMMDD_HHMMSS.log`，首次开启选择目录并记忆；记录解码后的会话文本（与终端显示一致），关闭开关或弹窗即收尾文件。
- 修复 App 侧进度条打印期间提示符碎片累积（"每次进度多一个 `/$ root:`"）：设备每帧以 `ESC[2K` 清整行重绘，终端现已实现 Erase-in-Line 序列（EL0/1/2）。
- 修复 Boot 进度条与 shell 提示符交错时的半替换碎片：挂起的 `\r` 不再在 TCP 包尾提前决断，语义推迟到下一字符到达。
- 终端渲染经真实设备字节流回放验证：99 帧预擦进度收敛单行、日志行提示符前缀正确清除。

## 已知边界

- ` 3B initialized=...` 一类的行首截断为设备侧残缺发送（上位机 transcript 证据确认），非上位机渲染问题。
- Boot 阶段 shell 提示符与 OTA 进度条为设备侧并发输出，哑终端下交错拼接仍会出现（Serial 等终端同字节流同样如此）。
- 会话日志记录的是解码文本；原始字节证据仍完整保存于 `tcp_shell_sessions/`。
