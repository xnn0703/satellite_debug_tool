# M19-A.12 运动停止与姿态精度解耦实施计划

## 1. 目标

- 将运动平台的“机械运动已经停止”和“最终位置精度满足测试要求”拆成两个独立结论。
- 平台控制组件只依据控制器健康状态、六轴静止窗口和执行器目标保护范围结束一次运动。
- 标定后的 MS-6222 负责 Roll/Pitch/Yaw 的稳态误差、噪声、响应时间和方向映射评价。
- 修正夹具姿态曲线的单位、坐标状态和数据缺口表达，使图表只展示已有证据。
- 为平台反馈补齐主机单调时间和墙上时间，允许与 MS-6222 证据按同一时间轴复核。

## 2. 本次现场证据

- 当前固定 `500 pulse` 到位阈值约等于 `0.0127 mm`，没有供应商精度合同依据。
- 2026-10-09 真机动作停止后的最大稳定残差分别约为 `661 / 989 / 1983 / 2191 pulse`，即 `0.0167 / 0.0250 / 0.0502 / 0.0555 mm`。
- 上述稳态阶段六轴约一秒内仅波动 `2..8 pulse`，继续等待不会进入原 500 pulse 阈值。
- 反馈中的路径计数保持为零，`reccmdret=0` 不能证明逐命令完成。
- Roll +3° 时 MS-6222 原始 Roll 由约 +0.245° 变为约 -2.72°，Roll -3° 时变为约 +3.20°；原始安装坐标中的 Roll 与平台逻辑 Roll 反向。
- 供应商上位机的六个单轴动作证据给出平台到 MS-6222 原始姿态的候选符号 `Roll -1 / Pitch +1 / Yaw -1`；本次三轴正弦的 Roll/Pitch/Yaw 同频同相，不能替代单轴复核。
- MS-6222 手册定义载体坐标为右前上 XYZ，旋转角描述从载体坐标到组合导航坐标的 Z-X-Y 旋转，航向项使用 Angle(-Z)。平台内部运动学使用自身 XYZ 右手旋转，两者不能直接假定同轴同号。
- 当前设备软件合同采用 FRD：Roll+ 为右翼下沉、Pitch+ 为机头上抬、Yaw+ 为向右/俯视顺时针。因此设备软件与 MS-6222 原始方向一致；相对摇摆台，Roll/Yaw 反号、Pitch 同号。设备实物方向仍由单轴自动资格测试确认。

## 3. 单一状态与动作结果

平台连接状态继续由 `MotionPlatformState` 独占。动作结果改为肯定、可审计的事实：

- `motion_stopped`：当前代际内收到连续静止窗口，控制器处于运行态且六轴无伺服错误。
- `target_guard_passed`：停止位置与目标执行器位置的最大偏差位于控制保护范围。
- `maximum_error_pulses` / `maximum_error_mm`：最终残差，始终保留原始值。
- `outcome`：`settled`、`settled_outside_target` 或 `home_confirmed`。

删除把 `completed=True` 同时解释为停止与精度通过的旧模型。

## 4. 停止判定

普通单点与轨迹末点必须同时满足：

1. 当前连接代际不变，反馈新鲜；
2. `system_state=4` 且六轴伺服错误为零；
3. 最近 300 ms 的每轴反馈峰峰值不超过 100 pulse；
4. 六轴最大目标残差不超过 0.1 mm，按档案几何换算为脉冲；
5. 条件持续成立到完整静止窗口结束。

0.1 mm 是控制流程保护范围，不是平台精度合格指标。档案和报告保存物理量，脉冲换算只在运动平台组件内完成。

若平台已经静止但残差超过保护范围，记录 `settled_outside_target`，连接状态回到 `READY`，本次动作失败但允许显式回中。只有反馈丢失、控制器重启或仍在运动时超时才进入 `RECOVERY_REQUIRED`；伺服错误进入 `FAULT`。

回原点继续使用专用状态链，并增加静止窗口；其零位保护范围与普通目标分开解释。

## 5. MS-6222 精度与方向

- 界面、配方、轨迹、自动资格测试和报告统一使用设备 FRD 正方向：Roll+ 右翼下沉、Pitch+ 机头上抬、Yaw+ 向右/俯视顺时针。
- 灵境型号档案固定执行 `Roll -1 / Pitch +1 / Yaw -1` 的 FRD 到供应商控制坐标转换；该转换属于型号事实，不允许作为安装参数编辑。
- 自动资格测试按中心、Roll±3°、Pitch±3°、Yaw±3°、中心顺序独立激励各轴。
- 每次平台报告 `motion_stopped` 后额外稳定 1 s，再采集 MS-6222 2 s。
- 首次完整测试生成 MS-6222 原始坐标到 FRD 的自派生工程映射：轴对应、符号、零偏、响应矩阵和串扰。
- 映射必须人工确认后保存；解码器保持供应商原始姿态，禁止直接把 Roll/Yaw 写死取反。
- 中心起止样本合并后的任一轴离散度必须不大于 0.1° 工程门限；超限时拒绝确认和保存，等待 MS-6222 航向稳定后重新执行资格测试。
- 已确认标定存在时，自动测试输出每阶段均值、标准差、稳态误差、响应延迟和方向一致性；精度阈值继续标记为工程阈值，等待平台正式指标冻结。
- 标定无效时只显示“原始安装坐标”，不生成目标误差结论。

## 6. 曲线与证据

- 联合页三个子图均固定使用 `deg`，关闭自动 SI 前缀，避免 `mdeg` 与 `deg` 混用。
- 使用短轴标题并为三行图分配足够高度，消除左侧标题重叠。
- 数据时间间隔超过正常采样间隔的保护倍数时插入断点，不跨缺口画连接线。
- 标定无效时隐藏目标误差曲线并明确显示原始坐标；标定有效后显示逻辑目标、标定后实测和误差。
- 每条平台命令、反馈、状态和动作事件写入 `host_monotonic_ns` 与 `host_wall_time_ns`。
- 轨迹完成事件分别记录计划点数、实际发送点数、跳过点数和最大调度迟到；“校验通过”只表示预检结果。
- 相位定义为“实测相位减目标相位”；延迟定义为其相反数，实测滞后输出正延迟，实测超前输出负延迟。

## 7. 实施顺序

1. 重构运动配置、动作结果与静止窗口判定，删除旧 500 pulse 单阈值模型。
2. 修正控制线程和 UI 对动作结果的解释，并保留失败动作证据。
3. 接通自动资格测试的停止结论与 MS-6222 稳态采集。
4. 修正联合曲线单位、布局、坐标状态和数据缺口。
5. 补齐平台证据主机时间戳和 manifest 内容。
6. 增加现场残差、静止超差、仍在运动超时、曲线单位/断点、时间对齐和方向映射回归测试。
7. 更新翻译、架构文档、开发记录，执行全量 pytest 与翻译检查。

## 8. 现场复测

- 重新运行自动资格测试，不再因 500 pulse 残差中止。
- 核对八个阶段均完成并生成 Roll/Pitch/Yaw 单轴响应矩阵。
- 人工确认自动识别的轴映射与符号后保存标定。
- 使用已确认标定再运行一次，检查三轴稳态误差、方向、响应时间和串扰。
