# 卫通终端管理工具 v1.9.13

发布日期：2026-11-17

本版包含 AFD01B2 实机 3D 模型机头轴向修复与 M73 自动更新已提交备份清理。

## B2 模型轴向修复

- AFD01B2 实机 STL 的机头轴由误配的 CAD X 长轴（298 mm）改为 Z 短轴
  （189.5 mm），三款同族面板统一为 `DeviceModelAxes(1,2,1,1)`（X=翼、Y=厚度、
  Z=机头），修复前俯仰在 3D 视图中显示为横滚。
- 旧映射同时是镜像变换（det=-1），接插件显示在错误一侧；修正后接插件回到设备
  右侧，与实机俯视图一致。
- 新增几何回归测试：三款实机模型轴映射必须是真旋转（机头×左翼=天顶）且机头
  跨度小于翼跨度；B2 接插件凸出簇必须落在右侧端。旧配置下三条回归稳定复现
  失败，新配置全部通过。

## 自动更新已提交备份清理（M73）

- `InstallJournal.release_committed_backup()` 是提交后备份释放的唯一入口：
  journal `committed` 后删除回滚副本并保存 `released`，首次安装保存
  `new_install`，删除失败保存 `cleanup_required` 并保留登录恢复入口。
- 成功事务顺序统一为：健康回执 → committed 持久化 → 提交回执 → 备份释放 →
  completed → 移除登录恢复入口。
- 提交后中断的 `--recover` 复用同一释放接口，先补发健康提交回执再释放遗留
  备份，不回滚已提交新版。
- 修复前备份在事务已不可回滚后仍长期占用约一份完整应用空间；v1.9.12 真实
  事务的遗留备份已按文件事实补记 `released`。

## 验证范围

- 源码全量回归、翻译检查、字节码编译及差异检查通过后才创建发行标签。
- Windows 候选继续由 GitHub Actions 构建；macOS 候选继续由发布 Mac 构建；
  两平台 ops 进入同一 TUF publication。
- 本版不生成差量包，运维版自动更新下载经过签名目录和 SHA-256 校验的完整
  安装包。
- user 版不启用应用自动更新，继续通过服务器完整安装包人工交付。
