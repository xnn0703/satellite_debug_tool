# M49 验收标准

状态：用户已确认，与 M49 计划对应。

1. 预存电源 host 后，启动应用、进入客户页面、连接/断开设备、打开工具、离开/返回页面均不因页面活动自行创建客户电源连接；显式连接一次只产生一个 worker。停止/返回本地保持停止，客户与自动化共享电源的所有权切换无需额外手动关掉自动产生的客户会话。
2. 同一窗口尺寸下在线→离线→重连→过期及中英切换保持外框大小，关键按钮/端点/电源状态可达，关键数值和状态可读；最小支持尺寸和常用宽屏均有实际 Qt 几何/截图验证。
3. 自动化工作区可见标题及同义入口采用“自动化测试 / Automated testing”；内部批次、历史记录和配方合同保持。TS/QM 同步，check 通过。
4. 连续录制期间多次打开、连接、关闭 Shell 和摇摆台弹窗，保持原 Runtime/recorder lease 和输出文件；注入带序号的遥测帧并验证 SDB 全部到达。页面隐藏与弹窗焦点变化不产生录制 stop/finalize；真实断连/重启按原合同保留事实。实际偶发问题若暂未稳定复现，明确记录已证实与未证实的边界，不能声称根因消除。
5. Shell 空闲连接、持续接收、串口及 YMODEM 分别验证：确认一次后自动完成断开/排空/日志/租约收尾并关闭原窗口；不用先手动断开 TCP，不重复弹窗；取消保持原状态；失败明确反馈，主界面持续响应。
6. 相邻入口覆盖用户版/运维版、主窗口退出、Shell 自身关闭、自动更新受控退出及既有批次/录制收尾；关闭顺序明确，不能先释放共享会话再等待 Shell。
7. 每项根因有旧行为可复现、新实现可通过的回归。完成相关测试和全量 pytest，失败按真实回归处理；开发记录逐项对照计划。不提交、不打包，不发送现场硬件控制命令。
