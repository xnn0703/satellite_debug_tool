# M61 摇摆台固定 20 ms 连续轨迹验收标准

## A. 软件

- [x] 连续轨迹只有一个20 ms周期常量，领域构造、界面和正式执行不存在可变周期入口。
- [x] 所有连续轨迹位置帧动作时长均为20 ms。
- [x] 工程摇摆台页面不显示采样周期控件。
- [x] 新生产配方保存固定20 ms证据，非20 ms配方不能进入当前正式执行。
- [x] 独立进程20 ms loopback发送不少于100点，无跳点、无重复发送owner。
- [x] 20 ms缓停渐出与反馈闭环回正通过。
- [x] 定向测试、翻译检查、差异检查及全量测试通过。

## B. 现场

- [ ] 10°三轴连续运行不少于10 min，pcap无持续完整槽位丢失。
- [ ] 20 ms指令的P95/P99、最大间隔及控制空洞形成新基线。
- [ ] 控制器反馈连续，六轴伺服错误为0。
- [ ] MS-6222曲线和现场观察确认周期性机械声相对50 ms工况明显降低。
- [ ] 15°组合姿态单独验证可达包线、声音和缓停回正，不以单轴±30°替代组合包线结论。
