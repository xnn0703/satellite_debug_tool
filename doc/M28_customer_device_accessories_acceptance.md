# M28 客户设备独立电源与 iperf3 验收标准

状态：软件验收完成；现场验收 BLOCKED（本轮未连接两台客户设备、两台 PSW80-27 和实际 ECS 端口）

计划：`doc/M28_customer_device_accessories_plan.md`

开发记录：`doc/M28_customer_device_accessories_dev_log.md`

## A. 配置与迁移

- [x] 每个 `customer.devices[]` 具有稳定且唯一的 `device_id`；编辑 endpoint 后 ID 与 accessory 配置保持不变。
- [x] 最多 4 台设备分别持久化电源 profile 和 iperf profile，重启后无字段丢失或跨设备覆盖。
- [x] 单设备旧配置迁移到该设备；多设备旧配置只迁移到当时活动设备，其他设备保持“未配置”。
- [x] 迁移具有版本标记并可幂等重启；主配置/备份/原子写失败沿用现有阻断语义。
- [x] iperf3 可执行文件是主机级配置，其余测试参数是设备级配置。

## B. 外接电源

- [x] 全局设置页不再显示 Customer 外接电源配置；每台设备 Overview 的外接电源弹窗可独立保存 IP、设定电压和设定电流。
- [x] `PSW80-27`、`PSW 80-27` 归一化为同一支持型号，其他厂家/型号仍明确拒绝。
- [x] 每台设备只有一个串行电源 owner；采样和控制不建立竞争 socket，也不保留被取代的严格只读 owner。
- [x] 弹窗显示绑定设备、身份、输出、保护、V/A/W 和最近 30 分钟 V/A 曲线。
- [x] 应用参数前确认输出关闭并回读电压/电流设定；开启、关闭输出均以状态和测量回读确认。
- [x] UI 分别呈现命令发送、设定值确认、输出确认和电压确认，不用发送成功冒充物理状态。
- [x] 编辑未保存文本、切换设备、关闭弹窗、断线重连和应用启动均不自动改变电源输出。
- [x] 同一电源 IP 不能保存给两个客户设备；客户控制动作、输出开启或网络测试活动时明确阻止进入 Production，切换工作区会先停止全部客户电源会话。
- [ ] 退出时对确认开启的各台电源逐台列出；用户选择和最终证据被记录，失败不显示为已关闭。

## C. iperf3 多设备

- [x] Network test 使用设备级固定页面栈；切换设备后页面配置、状态、曲线和事件均切换到对应固定 Store。
- [x] 每台设备最多一场活动测试；其他设备测试不因页面隐藏或切换设备而停止。
- [x] 不同本地 IPv4且服务端端口不冲突的设备测试可并行运行。
- [x] 相同本地 IPv4或相同 `(server, protocol, port)` 的并行启动被拒绝，错误指出冲突设备和资源。
- [x] 一个设备停止、失败或完成不改变其他设备 controller、进程、重试计时器或 Store。
- [x] 应用退出停止全部活动 controller，UL/DL 子进程和会话文件均完成收尾。
- [x] 电源不可用时测试可继续，但功耗状态明确为不可用，且不接收其他设备电源样本。

## D. 记录与隔离

- [x] 每台设备录制只写入其绑定电源的 `external_power_sample/v1`；同时录制时样本不广播串台。
- [x] 电源样本与控制结果事件包含稳定 `device_id`、当时 endpoint、电源身份和连接代次。
- [x] 每个 iperf 会话包含稳定 `device_id`、启动 endpoint、设备级测试配置和对应电源身份/不可用事实。
- [x] 修改设备 endpoint 后，旧证据仍能通过稳定 ID 追溯，且新会话记录新 endpoint。
- [x] 删除设备前若电源动作、输出确认开启、录制或 iperf 测试活动，删除被阻止并给出具体状态。
