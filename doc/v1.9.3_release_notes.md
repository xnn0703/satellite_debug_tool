# 卫通终端管理工具 v1.9.3

发布日期：2026-11-03

本版包含 v1.9.2 计划交付的全部 M56～M60 更新，并修复 Windows 发布门禁发现的完整采集覆盖时长问题。

## 相对 v1.9.2 候选的修复

- FULL 采集覆盖持续时间改由高分辨率单调时钟计算；墙钟只保存录制开始/停止时间。
- SDB summary 明确保存 `support_full_intervals_monotonic_ns`，避免 Windows 墙钟分辨率导致真实区间被记录成 0。

## 主要更新

- macOS 运维版事务自动更新、失败回滚和登录恢复；本版是从 v1.9.1 人工过渡到后续自动更新的桥接版本。
- ECS 本机完整 SHA-256 发布复核，减少公网带宽争用。
- 设备上线前预录制、完整采集阶段证据、轨迹预编译、缓停回正和独立运动发送时间线。

## 发行边界

- 用户版继续人工完整包交付；macOS arm64 为 ad-hoc 签名，未 Apple notarization。
- 软件与归档验证不替代 Windows 实机、设备、RF、供电和摇摆台现场验收。
