# M19-A.3 PSW 电源独立调试页计划

## 目标

在 Production Workspace 增加独立的“电源调试”页面，使操作者无需创建批次、连接 DUT 或启动摇摆台会话，即可验证 GW Instek PSW 80-27 的 TCP/SCPI 身份、状态读取、输出 OFF 预检、设定值闭环、输出开启和输出关闭。

本页面只形成工程调试证据，不接入 M19 批次自动流程，不产生设备 PASS，不把电源总电流解释为单台 DUT 电流。

## 当前事实

- `core/production/power_supply.py` 已实现 `GwInstekPswAdapter`、TCP LF 组帧、身份白名单、状态查询、OFF 预检、设定值读回、OUTPUT ON/OFF 闭环、保护检查和断线后不重放 OUTPUT ON。
- 当前应用没有调用该适配器的 UI，只有单元测试能够覆盖它。
- 电源正式需求电压、电流和电源 SN 尚未由现场冻结；页面不得隐式采用 MATLAB 示例的 14 V/2 A。验证窗口按 PSW80-27 官方精度与分辨率自动生成。
- Production Workspace 已有批次测试与夹具调试二级页面，两者共享 `FixtureControlLease`。

## 实施范围

### 1. 独立页面与控制所有权

- 在 Production Workspace 增加第三个“电源调试”页面，并使用 `LazyViewHost` 首次访问构建。
- 电源连接期间持有现有 `FixtureControlLease`；批次、摇摆台调试和电源调试三者互斥。
- 电源调试不要求批次、配方、DUT 或摇摆台档案。
- 页面隐藏、应用退出或断开连接时不自动开启输出，不自动恢复上次状态。
- 输出已确认开启或状态未知时，离开页面、断开连接和关闭应用必须显示当前事实，并要求操作者明确处理；软件不得把 TCP 断开描述为电源已关闭。

### 2. 需求配置与自动验证

- 页面输入字段包含：IPv4、端口、期望厂家、期望型号、可选 SN、设定电压、设定电流、连接超时、命令超时和输出稳定超时。
- 厂家和型号可按已确认产品合同预填 `GW-INSTEK`、`PSW 80-27`，端口可预填 `2268`。
- 操作者只填写本次需求电压和电流；设定值读回容差、开启电压窗口和关断电压阈值由唯一的 PSW80-27 验证策略计算并只读显示。
- 需求值必须满足 `0 < V ≤ 80 V`、`0 < I ≤ 27 A` 和 `V × I ≤ 720 W`；不满足时禁止连接和所有写操作。
- 不提供任意 SCPI 命令输入框，不提供 OVP/OCP 清除、远程急停或自动循环开关。

### 3. 操作与状态

页面提供以下操作：

1. **连接并识别**：建立 TCP，只执行 `*IDN?`；厂家、型号或可选 SN 不匹配时关闭连接并明确拒绝。
2. **读取状态**：只读执行 `OUTP?`、`MEAS:ALL?`、`STAT:OPER:COND?`、`STAT:QUES:COND?`、`OUTP:PROT:TRIP?`。
3. **应用参数并确认 OFF**：显式发送 `OUTP 0`，在稳定期限内确认输出关闭和电压下降，再写入电压/电流设定值，执行 `*OPC?`、设定值读回和错误队列检查；成功后状态为 `READY_OFF`。
4. **开启输出**：身份已验证后即可操作；一次确认自动完成 OFF 准备、参数写入和闭环开启。只有 `OUTP?=1`、实测电压在稳定期限内进入自动窗口且无保护状态时显示“输出已确认开启”。
5. **关闭输出**：连接存在时始终可操作；只有 `OUTP?=0` 且实测电压不高于断电门限时显示“输出已确认关闭”。
6. **返回本地**：发送 `SYST:COMM:RLST LOC`，页面明确提示该命令不改变输出状态。
7. **断开连接**：关闭 TCP；断开后状态为“未连接”，不保留“输出已关闭”推断。

- 网络操作必须在后台串行执行，不能阻塞 Qt 主线程，也不能并发读取同一 TCP 连接。
- 写操作进行期间禁用其他写按钮；“关闭输出”保留为优先操作意图，但不宣称取代电源面板 OUTPUT 键或实体安全回路。

### 4. 显示与工程证据

- 页面显示身份原始字符串、厂家、型号、SN、固件、连接代次、当前状态和证据等级。
- 状态区域显示逻辑输出、实测电压、总电流、运行状态字、告警状态字和保护触发状态。
- 命令记录显示时间、命令、查询响应和 action ID；命令发送、状态回读、电压确认分别呈现。
- 调试会话保存到 `~/.satellite_debug_tool/power_supply_sessions/<session_id>/`，至少包含配置快照、身份、SCPI 记录、操作结果、事件和最终状态。
- 配置快照标记 `ENGINEERING_ONLY`；不保存为生产配方，不生成正式测试报告。

### 5. 生命周期与故障语义

- TCP 超时、额外响应、空响应、非 ASCII、身份不匹配、设定值不匹配、保护触发和实测电压越界均显示原始原因。
- 通信失败后状态进入 `UNKNOWN`；重新连接只读取身份，不自动准备、开启或关闭输出。
- 页面关闭前等待后台操作结束；无法确认最终状态时保留会话为 `INCOMPLETE`。
- 应用退出不发送隐式 OUTPUT ON；如果操作者选择断开但保留输出，记录该决定和当时最后一次已确认状态。

## 验证顺序

1. 使用脚本化 transport 完成 UI 单元测试，覆盖所有操作和失败路径。
2. 运行现有 `test_power_supply.py`、Production Workspace、夹具调试和新增测试。
3. 执行翻译 `update` 与 `check`。
4. 运行全量 `PYTHONPATH=. pytest satellite_debug_tool/tests -q`。
5. 现场先做“连接并识别”和“读取状态”，确认不会写输出。
6. 空载或经批准的安全负载下执行 OFF 预检、自动验证限制核对与设定值读回。
7. 在实体 OUTPUT/急停可触达、支路保护已确认后，执行一次开启、读取和关闭闭环。
8. 验证 TCP 断线、应用重启和身份不匹配均不会自动开启输出。

## 不在本轮范围

- 不接入批次自动工况或 DUT Boot Session。
- 不实现周期性自动开关、电源压力测试或自动重试 OUTPUT ON。
- 不修改 `GwInstekPswAdapter` 已确认的状态模型，除非 UI 接入暴露出可稳定复现的根因缺陷。
- 不将单通道总电流换算成单台 DUT 功耗。
- 不替代实体 OUTPUT、急停、支路保险丝或独立安全回路。
