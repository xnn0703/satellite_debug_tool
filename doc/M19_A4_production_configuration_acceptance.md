# M19-A.4 可视化试产配置与批次生成验收标准

## A. 批次操作

- [x] 批次页面无需手写或导入 JSON 即可创建批次。
- [x] 页面可选择已注册产品模板、`1..4` 台设备和工作站配置。
- [x] 选择 `AFD01C × 2` 后摘要明确显示产品、数量、单台供电、合计供电和测试概要。
- [x] 创建批次后锁定选择项，批次目录保存完整不可变配置快照和 SHA-256。
- [x] 已创建批次不受之后设置修改、档案更新或配置包导入影响。

## B. 自动计算

- [x] AFD01C 模板配置单台 `12 V / 8 A` 时，`×2` 自动得到 `12 V / 16 A / 192 W`。
- [x] 电源额定电压、电流或功率不足时禁止创建批次，并显示具体超限项。
- [x] 支路数量不足或单支路能力不足时禁止创建批次。
- [x] 当前只使用模板中的显式数值，不增加隐藏裕量。
- [x] 电源电流是共享输出限流上限，不将总电流平均值作为单台功耗证据。

## C. 产品数量门禁

- [x] `AFD01C × 2` 只有在恰好 2 台 AFD01C 身份确认且证据录制就绪时允许启动。
- [x] 只有 1 台、出现第 3 台、混入 AFD01、身份冲突或唯一身份缺失时禁止启动并显示原因。
- [x] 启动时冻结两台参与设备的不可变身份，运行中掉线或替换不会自动补位。
- [x] AFD01 与 AFD01C 使用各自注册产品合同，名称相近不会被视为同一型号。

## D. 配置管理

- [x] 设置页提供“试产配置…”入口。
- [x] 产品模板可维护产品 ID、单台供电、固件/参数期望、测试项目和时长。
- [x] 电源档案可维护注册驱动、厂家、型号、IP、端口、可选 SN 和额定容量。
- [x] 工作站配置可组合电源、摇摆台、参考设备及支路能力。
- [x] 所有档案包含稳定 ID、revision、schema version 和 SHA-256，并通过原子写入保存。
- [x] 设置只保存上次选择的档案 ID；运行状态和 OUTPUT ON 意图不持久化。

## E. 电源合同

- [x] 型号选择只列出已注册驱动；首版只提供 GW Instek PSW80-27。
- [x] 正式批次启动前按档案执行真实 `*IDN?`，厂家、型号和可选 SN 不匹配时拒绝控制。
- [x] 电源容量校验、OUTPUT OFF 准备、参数设置、OUTPUT ON 稳定确认和保护状态形成同一条可追踪证据链。
- [x] 批次、夹具调试和电源调试继续通过唯一控制租约互斥。
- [x] TCP 连接、指令发送、设备回读和实测电压分别陈述，不把发送成功描述为已供电。

## F. 导入导出

- [x] 可将工作站配置、产品模板和电源档案导出为单一版本化 JSON 配置包。
- [x] 另一台电脑可以通过界面导入并在批次页面直接选择。
- [x] 导入先完整验证后原子提交，不产生半导入状态。
- [x] 同 ID/revision 但 SHA-256 不同的对象明确报冲突且不覆盖。
- [x] 配置包不包含输出状态、自动开启意图、批次号或运行证据。

## G. 兼容和迁移

- [ ] 现有 schema v1 配方缺少供电需求和可解析档案，不能无损自动转换；需要由操作者在表单中补齐后保存为新模板。
- [x] 批次页面不再暴露旧的“导入配方”日常入口。
- [x] 历史批次的 recipe/config 快照仍可读取和用于报告追溯。
- [x] 新批次只由 `ProductionConfigurationStore` 生成配置快照；旧配方读取接口仅服务历史数据和迁移测试。

## H. 自动化与界面验证

- [x] 模型和 Store 测试覆盖校验、revision、SHA-256、原子保存、冲突和配置包完整性。
- [x] UI 测试覆盖 `AFD01C × 2` 正常计算、电源容量不足、数量不足/超量、型号混入和批次冻结。
- [x] 正式批次电源测试覆盖身份拒绝、OFF/ON 闭环、保护触发、断线和不重放 OUTPUT ON。
- [ ] 1024×600、1280×800 已完成离屏检查；Windows DPI 待 Windows 实机验证。
- [x] 中英文翻译 `update`、`check` 通过。
- [x] 全量 `PYTHONPATH=. pytest satellite_debug_tool/tests -q` 通过且无新增 warning。

## I. 真机验收

- [ ] 使用两台真实 AFD01C 和一台 PSW80-27 完成 `AFD01C × 2` 配置、身份门禁和供电闭环。
- [ ] 电源面板、两路支路保护、实测输出和软件证据一致。
- [ ] 少接一台、多接一台、接入 AFD01 或更换未登记电源时均被正确阻止。
- [ ] 配置包在另一台工作站导入后，可以复现相同摘要、SHA-256 和启动门禁。

> 软件自动计算和主机测试只证明配置与控制链行为。正式放行仍需真实设备、电源、支路保护、摇摆台和报告复核共同通过。
