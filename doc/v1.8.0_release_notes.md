# v1.8.0 发布说明

本版本开始提供独立用户版和完整运维版。已有全量版继续升级为运维版；面向客户可选择轻量用户版。

## 下载选择

| 版本 | Windows 资产 | 功能 |
|---|---|---|
| 用户版 | `satellite_terminal_tool-user-windows-v1.8.0.7z` | 总览、射频控制、录制/回放、加密固件升级、Shell（TCP/串口/YMODEM） |
| 运维版 | `satellite_debug_tool-win-v1.8.0.7z` | 全量客户、工程诊断、网络/电源、摇摆台、试产及测试工具 |

使用 7-Zip 解压对应包，运行 `SatelliteDebugTool.exe`。两版使用独立安装目录和设置，用户版首次使用需要显式添加设备；旧全量版配置继续由运维版读取。应用内更新按版本类型选包。

## 主要更新

- 用户版保留 SNR 最近五分钟曲线、底部三模块温度、客户 RF 控制及认证固件升级；Shell 按需打开，支持 TCP、串口和 YMODEM。
- 三主题统一为石墨灰/中性浅灰与蓝色操作色，完善状态色、曲线及终端颜色；更新应用图标与中性产品名称。
- 修复回放/日志时间范围下拉框的字体、选项裁切和英文工具栏布局。
- Shell 增加串口连接、接收时间戳、等宽终端与光标呈现；YMODEM 采用 SOH/128 头包及批结束、STX/1024 数据块，并为设备存储操作保留 ACK 等待窗口。
- 两版共享设备会话、数据与 OTA 状态机；更新前验证 edition/platform/version，保持用户与运维包的归属。

## 使用说明与验证范围

- Shell 命令建议使用英文/ABC 输入法。中文输入法可能把 Shift+- 转成破折号、把部分符号转成全角字符。
- Windows 发行流程分别构建、离屏启动检查两版冻结程序，并验证总览、Shell、正常退出和归档身份。
- macOS 两版由本地脚本生成签名 app/zip，单独分发；当前应用内自动安装仍以 Windows 资产为合同。
- 软件回归与包检查覆盖构建、装配和软件行为；实际 Windows 显卡上的 3D 渲染、设备升级、射频和夹具动作以现场证据验收。Windows 3D 需要支持 OpenGL 2.1 或更高版本的图形驱动；云端 Runner 的原生图形后端未作为渲染通过证据。
